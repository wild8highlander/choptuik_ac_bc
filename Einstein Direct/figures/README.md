# figures/ — Publication Figures (RU/EN, 300 dpi)

All figures of the parent folder are generated by the machines themselves and
stored here in two parallel variants: `fig_ru/` (Russian labels) and `fig_en/`
(English labels). Both variants are rendered at 300 dpi PNG and are produced
by the same code path, so they never diverge in content.

## What is inside

| File (both variants) | Produced by | Content |
|---|---|---|
| `fig_scaling.png` | `figures.py` | fixed-grid mass scaling and the critical amplitude |
| `fig_evolution.png` | `figures.py` | double-null evolution snapshot of a supercritical run |
| `fig_validation.png` | `figures.py` | validation suite summary (Roberts–Oshiro, flat space) |
| `fig_spinor.png` | `spinor_figures.py` | spinor even/odd decomposition and wall diagnostics |
| `fig_modes.png` | `hexcycle_figures.py` | center-tower modes at the critical scale |
| `fig_hexcycle.png` | `hexcycle_figures.py` | the hexagonal station wheel |
| `fig_hexcycle_dynamics.png` | `hexcycle_figures.py` | cycle dynamics: books along the march |
| `fig_hexcycle_closure.png` | `hexcycle_figures.py` | clock closure across the cycle |
| `fig_tau_hexcheck.png` | `hexcheck_figures.py` | τ-book (fresh fits) and clocks of near-critical chains |
| `fig_w2_hexcheck.png` | `hexcheck_figures.py` | W2/t0² measurement floor and the live tower |

## How to regenerate

```bash
python3 figures.py           # base campaign figures
python3 spinor_figures.py    # spinor figures
python3 hexcycle_figures.py  # hexcycle figures
python3 hexcheck_figures.py  # hexcheck campaign figures (reads results/grid_machine_hexcheck.json)
```

## Notes

- Figures are outputs, not inputs: nothing downstream reads them. Deleting
  the folder is safe; every machine regenerates what it needs.
- The matplotlib backends are forced to `Agg`; runs are single-threaded and
  deterministic, so regenerated figures match the committed ones to the pixel
  on the same stack.
