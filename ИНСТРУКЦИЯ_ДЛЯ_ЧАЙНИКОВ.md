## Что вообще происходит (в двух словах)

1. У вас есть репозиторий на GitHub, и в нём есть ошибки (CLI падает,
   бейджи красные).
2. Этот ZIP-архив содержит **исправленные файлы** + **скрипт-автомат**,
   который сам закоммитит и отправит их на GitHub.
3. От вас нужно: установить Termux → скопировать архив на телефон →
   ввести один раз токен → нажать одну команду. Дальше скрипт всё сделает
   сам. Токен — это «пароль для программ», получить его проще, чем кажется
   (шаг F).

# ЧАСТЬ A. Устанавливаем Termux

> **ВАЖНО: Termux ставится ТОЛЬКО из F-Droid или с GitHub-релизов.
> Версия из Google Play устарела, сломана и не будет работать.**

**Шаг A1.** Откройте в браузере телефона: https://f-droid.org/packages/com.termux/

**Шаг A2.** Нажмите **Download APK**. Android может спросить
«разрешить установку из этого источника?» — разрешите.

**Шаг A3.** Установите APK (как обычное приложение).

**Шаг A4.** Откройте Termux. Появится чёрный экран со строкой
`~ $` — это и есть командная строка. Клавиатура вызывается тапом по экрану.

**Проверка:** вы видите приглашение вида `localhost ~ $` (точный текст
может отличаться — это нормально).

# ЧАСТЬ B. Первичная настройка Termux (один раз)

Ниже — команды. Их нужно **набирать точно** (или скопировать — как
копировать, см. «Шпаргалка» в конце) и после каждой нажимать Enter.
Первая команда может работать 1–5 минут — это нормально.

**Шаг B1.** Обновляем каталог пакетов:
```bash
pkg update -y && pkg upgrade -y
```
Если посреди появится фиолетовый экран с текстом и кнопками — нажмите
Tab чтобы выбрать **OK**, затем Enter. Если спросит `Continue? [Y/n]` —
жмите Enter (по умолчанию Y).

**Шаг B2.** Даём Termux доступ к памяти телефона (к папке Downloads):
```bash
termux-setup-storage
```
Android покажет окно «Разрешить Termux доступ к файлам?» — нажмите
**РАЗРЕШИТЬ**. Если окно не появилось, а команда прошла молча — тоже
нормально, доступ уже был.

**Шаг B3.** Ставим нужные утилиты (git — отправка на GitHub, unzip —
распаковка архива):
```bash
pkg install -y git unzip
```

**Проверка:** введите `git --version` — должно напечатать что-то вроде
`git version 2.4x.x`.

**Шаг B4.** (Совет) Чтобы Android не «усыпил» Termux во время долгих
операций:
```bash
termux-wake-lock
```
В строке состояния появится иконка замка/уведомление Termux — так и надо.

# ЧАСТЬ C. Перекидываем архив на телефон

**Шаг C1.** Скачайте ZIP-архив `choptuik_ac_bc_fixes_2026-09-22.zip`
из этого чата на телефон. Он попадёт в папку **Загрузки / Downloads**.

**Шаг C2.** Скопируйте архив в домашнюю папку Termux:
```bash
cp /sdcard/Download/choptuik_ac_bc_fixes_2026-09-22.zip ~/
```
Если у вас другая папка загрузок (например `/sdcard/Telegram/...`),
подставьте свой путь — главное, чтобы файл оказался в `~/`.

**Проверка:** команда `ls ~/` показывает ваш ZIP-файл в списке.

# ЧАСТЬ D. Клонируем репозиторий

> Репозиторий большой: **~270 МБ истории git + ~200 МБ файлов**,
> итого около 500 МБ. Нужно свободное место и Wi-Fi. Клонирование займёт
> от 3 до 15 минут в зависимости от скорости.

**Шаг D1.** Настройте git — кто будет автором коммитов:
```bash
git config --global user.name "wild8highlander"
git config --global user.email "wild8highlander@users.noreply.github.com"
```

**Шаг D2.** Клонируйте репозиторий (одной строкой):
```bash
git clone https://github.com/wild8highlander/choptuik_ac_bc.git ~/choptuik_ac_bc
```

**Шаг D3.** Перейдите в папку:
```bash
cd ~/choptuik_ac_bc
```

**Проверка:** `ls` показывает `README.md`, `python`, `code`,
`audit_transfer` и другие папки.

> СОВЕТ: Если Wi-Fi медленный, можно склонировать только последнюю версию
> без истории (быстрее, ~200 МБ):
> `git clone --depth 1 https://github.com/wild8highlander/choptuik_ac_bc.git ~/choptuik_ac_bc`
> Если позже при пуше будут жалобы на историю — один раз выполните
> `git fetch --unshallow`.

# ЧАСТЬ E. Распаковываем исправления поверх клона

**Шаг E1.** Находясь в `~/choptuik_ac_bc`, распакуйте архив **с заменой
файлов**:
```bash
cd ~/choptuik_ac_bc
unzip -o ~/choptuik_ac_bc_fixes_2026-09-22.zip -d .
```
Флаг `-o` означает «перезаписывать старые файлы новыми» — это и нужно.

**Проверка:** в списке распакованных файлов видны
`termux/choptuik_push.sh`, `FIXES_APPLIED.md`, `ИНСТРУКЦИЯ_ДЛЯ_ЧАЙНИКОВ.md`
и строки `inflating: .github/workflows/...`.

**Шаг E2.** Убедитесь, что скрипты исполняемые:
```bash
chmod +x termux/*.sh
```

# ЧАСТЬ F. Получаем PAT-токен GitHub (это «пароль» для скрипта)

Токен нужен один раз — потом он хранится на телефоне.

**Шаг F1.** На телефоне откройте браузер и войдите на GitHub под своим
логином (если ещё не вошли).

**Шаг F2.** Откройте готовую ссылку (scope `repo` уже предвыбран):
https://github.com/settings/tokens/new?scopes=repo&description=Termux%20choptuik%20push

**Шаг F3.** На странице:
- **Note** — любое имя, например `Termux choptuik push` (уже вписано);
- **Expiration** — выберите срок: 90 дней / No expiration (без срока);
- галочка **repo** должна стоять (ставится автоматически по ссылке);
- нажмите зелёную кнопку **Generate token** внизу.

**Шаг F4.** Появится токен — длинная строка вида `ghp_XXXXXXXXXXXXXXXXXXXX`.
**Скопируйте её прямо сейчас** (нажмите на значок копии рядом с токеном).
После ухода со страницы токен больше НЕ покажут — только пересоздавать.

Никому не пересылайте токен. Токен — это доступ к вашему GitHub.

# ЧАСТЬ G. Публикуем исправления (главная команда!)

**Шаг G1.** Запустите скрипт-автомат:
```bash
bash ~/choptuik_ac_bc/termux/choptuik_push.sh
```

**Шаг G2.** Скрипт сам:
1. найдёт репозиторий [v]
2. проверит ветку `main` [v]
3. увидит, что токена нет, и покажет рамку с просьбой его вставить —
   **вставьте токен** (долгий тап по экрану Termux → Paste) и Enter;
4. проверит токен на сервере GitHub [v]
5. сохранит его (файл `~/.git-credentials`, права 600 — доступен только
   вам) [v]
6. добавит все исправления, сделает коммит [v]
7. отправит на GitHub [v]

**Проверка:** в конце видно `[OK] Push успешный!` и раздел «6/6 Готово».

**Шаг G3.** Откройте в браузере
https://github.com/wild8highlander/choptuik_ac_bc
— сверху видно свежий коммит с сообщением
`fix: termux pack — CLI EOF/mode fixes, ...`.

> СОВЕТ: Второй и все последующие запуски пройдут без вопросов: токен уже
> сохранён. Если измените файлы в репозитории — тот же скрипт закоммитит
> и отправит их.

# ЧАСТЬ H. Кнопка пуша на рабочем столе («доверенная папка»)

В Termux есть «доверенная папка» — `~/.shortcuts`. Скрипты оттуда
приложение **Termux:Widget** запускает одним тапом с рабочего стола,
без вопросов и подтверждений.

**Шаг H1.** Установите ярлык:
```bash
bash ~/choptuik_ac_bc/termux/install_shortcut.sh
```
Скрипт создаст `~/.shortcuts/choptuik-push.sh` и впишет в него путь к
репозиторию.

**Шаг H2.** Установите приложение **Termux:Widget** — тоже из F-Droid:
https://f-droid.org/packages/com.termux.widget/

**Шаг H3.** На рабочем столе Android: долгий тап по пустому месту →
**Виджеты** → **Termux:Widget** → перетащите на экран → выберите
**choptuik-push.sh**.

**Шаг H4.** Тап по этой кнопке = автоматический коммит + push.
Первый раз спросит токен (если ещё не вводили), дальше — молча.

> СОВЕТ: Без виджета тоже работает: `bash ~/.shortcuts/choptuik-push.sh`

# ЧАСТЬ I. Если нужен форс-пуш

**Когда это бывает:** GitHub отклоняет обычный push, если на сервере
появились коммиты, которых нет у вас (например, правки вносились с
другого устройства или через сайт). Скрипт в этом случае НЕ перезаписывает
ничего сам — вы выбрали режим «форс только по флагу» — и печатает подсказку.

**Вариант 1 (безопасный, попробуйте сначала):** забрать изменения сервера
и наложить свои поверх:
```bash
cd ~/choptuik_ac_bc
git pull --rebase origin main
bash termux/choptuik_push.sh
```

**Вариант 2 (жёсткий, перезаписывает сервер вашей версией):**
```bash
bash ~/choptuik_ac_bc/termux/choptuik_push.sh --force
```
После `--force` коммиты, которые были на GitHub, но не было у вас,
**исчезнут** с ветки main (останутся только в истории сервера на время).
Используйте, только если уверены, что «серверная» версия не нужна.

**Посмотреть статус, ничего не отправляя:**
```bash
bash ~/choptuik_ac_bc/termux/choptuik_push.sh --status
```

# РЕШЕНИЕ ПРОБЛЕМ

| Симптом | Причина | Лечение |
|---|---|---|
| `command not found: git` (или unzip) | пакет не установлен | `pkg install -y git unzip` |
| `cp: cannot stat '/sdcard/Download/...'` | нет доступа к памяти или файл не там | выполните `termux-setup-storage` и разрешите доступ; проверьте имя файла `ls /sdcard/Download/` |
| `fatal: repository not found` при clone | опечатка в адресе / нет интернета | сверйте адрес посимвольно; проверьте сеть |
| Клонирование висит часами | большой репо, слабый Wi-Fi | используйте `--depth 1` (см. Часть D) |
| `remote: Invalid username or token` / `403` | токен неверен/протух | `rm ~/.git-credentials` и запустите скрипт снова — попросит новый токен |
| `! [rejected] ... fetch first` | на сервере есть чужие коммиты | Часть I: сначала `git pull --rebase origin main`, если не помогло — `--force` |
| `fatal: detected dubious ownership` | папка создана другим приложением | `git config --global --add safe.directory ~/choptuik_ac_bc` |
| `error: src refspec main ...` / «You are not currently on a branch» | вы в detached HEAD | `git checkout main` и повторите |
| Бейджи всё ещё красные через 20 минут | workflow не запустился | Actions → выбрать workflow → Run workflow (Часть J) |
| Termux закрывается при долгом клоне | Android уснул | `termux-wake-lock` перед работой; держите Termux открытым |
| Пишет «Изменений нет» а вы ждали пуш | коммит уже отправлен | всё в порядке — проверьте GitHub |
| ZIP распаковался «не туда» | забыли `-d .` | `cd ~/choptuik_ac_bc` и повторите `unzip -o ~/choptuik_ac_bc_fixes_2026-09-22.zip -d .` |

# ШПАРГАЛКА: копирование и вставка в Termux

- **Вставить:** долгий тап по экрану → **Paste** (или свайп сверху вниз —
  кнопки Ctrl/Tab/стрелки там тоже есть).
- **Копировать текст из Termux:** долгий тап → Select text.
- **Повтор предыдущей команды:** стрелка вверх ▲.
- **Прервать команду:** Ctrl + C (клавиша Ctrl — в дополнительной клавиатуре
  Termux, затем C).
- **Выйти из Termux:** наберите `exit`.
