# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 1.0.x   | Yes       |

## Reporting a Vulnerability

This is a mathematical verification project. If you find a computational error that affects the verification results, please:

1. Open a [Verification Discrepancy issue](https://github.com/wild8highlander/choptuik_ac_bc/issues/new?template=verification_discrepancy.md)
2. Include the computed vs. expected values
3. Specify which implementation (Python/Julia/Java/Viz) produced the discrepancy

For security vulnerabilities in the code itself, please email [aslan08_05@mail.ru](mailto:aslan08_05@mail.ru) directly.
