curvature spikes repeating with log-period **Δ ≈ 3.44**.

theorem $\tau^*(\delta) = 27/(4-\delta^2)$ on 12/12 bricks.

The **monograph line** computes the spectral invariants of the Klein quartic curve

Dirac operator, with applications to LIGO/Virgo QNM frequencies and the strong CP problem.
The **2026 bridges** extend this universality further: the **Collapse–Hawking Bridge**
(dimensionless birth profile → Hawking thermodynamics, IVP-15 audited) and the

### Step-by-step derivations

**1. From the spinor phase to the Berry quantum.** The trivial spinor bundle $\sigma_0$
on the Klein quartic gives $\lambda_1(D^2_{\sigma_0})=\lambda_1(\Delta)+R/4=3.838-0.5=3.338$
(Lichnerowicz, $R=-2$). Perturbing by the non-diagonal holonomy with phase $\delta$ shifts
the level at 2nd order in the phase: $\Delta\lambda=\delta^2/2$ — this is the Berry quantum.
For $\delta_C=\pi/7$: $\pi^2/98\approx0.1007$, and $\Delta_{bC}=3.338+0.1007=3.438710$.

**2. The braking quantum and the K3 Betti number.** The fourth power of the phase is
suppressed by the structural constant $k=b_2(K3)=22$: $\delta_{eff}=\delta^5/22$. For
$\pi/7$ this is $\pi^5/369754\approx1/1200$ — a "braking" that reduces the shift by three
orders of magnitude relative to the Berry term. The unified formula is
$\Delta_{Ch}=\lambda_1+\delta_C^2/2-\delta_C^5/22$; with higher orders
$\Delta_{Ch}=\Delta_{Ch}^{base}+\delta_C^4/8+\delta_C^6/2=3.447040$.

**3. The Choptuik constant as an identity of the septinial sector.**

$$
b_{Ch} \;=\; 1-\cos\!\Bigl(\frac{2\pi}{7}\Bigr) \;=\; 2\sin^2\!\Bigl(\frac{\pi}{7}\Bigr)
\;=\; 0.37651019814126640
$$

The identity is exact (mpmath 50 digits, pinned by `test_constants.py`); the gap to the
literature $\gamma_{Ch}=0.374$ is 0.67% and is served **only** as a comparison. In
audit_transfer the same formula in the generalization $1-\cos(2\pi/n)$ yields
$c_{K3}=b_{Ch}(22)=1-\cos(2\pi/22)=0.04036$ — the last empirical input value is derived
(residual 0.8% — finite-window systematics).

**4. Closing the clock with one brick.** Two "books" of the tower (the UV and Mdef
branches) give incompatible adiabatic clocks $9/4$ and $9/16$. De-adiabatisation dissolves
the contradiction: both branches close on **one** clock with a single common root

$$
\tau^*(\delta) \;=\; \frac{27}{4-\delta^2}\qquad\text{(exactly, SymPy, 12/12 bricks } \delta_k=\pi/k\text{)}
$$

and the additive Berry screening $\kappa=2-\pi^2/98$ (sector C!) moves $\ln\tau^*$ from
**−2.57 %** to **+0.062 %** of the observed scale — an observation with an open convention
question, not a fit.

### The engine from inside (2 030 lines, NumPy-only)

[`engine/solver.py`](Collapse%20Hawking%20Bridge/engine/solver.py) integrates the spherical
collapse system of a massless scalar field in double-null coordinates

$$
ds^2=-\alpha(u,v)^2\,du\,dv+r(u,v)^2\,d\Omega^2,\qquad
\begin{cases}
\text{(SC)}\ \Phi_{uv}\\
\text{(UV)}\ r_{uv}\\
\text{(C1)}\ r_{uu}=2\omega_u r_u-\tfrac{\kappa}{2}\,r\,\Phi_u^2\\
\text{(C2)}\ r_{vv}\\
\text{(TH)}\ \omega_{uv}
\end{cases}
$$

with the Misner–Sharp mass $m=\frac{r}{2}\bigl(1+4r_ur_v/\alpha^2\bigr)$ and regularity
identities up to the center $r=0$. The system is obtained by symbolic derivation (SymPy)
and verified on the exact Roberts–Oshiro solution at residuals ~1e-41; normalization
$4\pi G=1$ ($\kappa=2$, Burko 1996). The method is a characteristic march along v rows
(the Goursat problem), RK2-Heun (predictor–corrector), vectorized over u; the initial data
is the Choptuik Gaussian pulse $\Phi(u_0,v)=A\exp(-(v-v_p)^2/2\sigma^2)$. The horizon is
captured at $q=r_v<0$; stop reasons `completed / AH mass saturated / capture`;
diagnostics: `ah_found, m_ah, r_ah, v_ah, stopped_reason, c1_max, c2_max, mdef_max`.

### The "Ink & Gold" figure design system

All plots of the repository follow one style (the module
[`scripts/figstyle.py`](Collapse%20Hawking%20Bridge/scripts/figstyle.py)):

- **dark theme**: background `#0d0b08`, ink `#f2ead8`, gold `#d4af37`; **light**: background
  `#faf6ec`, ink `#1c1a15`, gold `#a8811c`;
- every figure is built in two languages (RU/EN — a 28-key label dictionary) and two
  themes — 4 variants per plot;
- 300 DPI for the READMEs (`figures/`) and 600 DPI for print/monographs (`figures_hires/`,
  4440×2880);
- zero RNG: everything is deterministic, a figure is reproduced from its JSON verdict by
  one command;
- the same style family is used by the root logo (`assets_logo/`, generator
  `make_root_logo.py`).

### The contract of a new campaign (how to add a result)

1. **Machine** — a deterministic script (BLAS = 1 thread, fixed seeds) that writes a JSON
   with the full run configuration next to the results;
2. **Verdict** — a status from the open set (exact / measured-law / honest-negative /
   anchor / INCONCLUSIVE / FAIL); FAILs and negatives are documented, never deleted;
3. **Pin** — a pytest test that fixes the key JSON numbers with a tolerance;
4. **Figure/animation** — from the committed JSON through a figstyle script (RU/EN ×
   light/dark);
5. **Twin** — the control quantities are duplicated in multilang implementations;
6. **Registry** — a row in the package's RESULTS/claim registry + an ERRATUM protocol if
   needed;
7. **README** — the campaign table and the reproduction index are updated by one command.

## Report formats and verdict styles

Each of the four implementations of the monograph stack generates reports in **all seven
formats**; every report starts with a results block and ends with a full execution log
(timestamps, configuration, provenance):

| Format | Extension | Purpose |
|---|---|---|
| Microsoft Word | `.docx` | formatted document with tables and figures |
| Portable Document | `.pdf` | publication readiness |
| Plain Text | `.txt` | human-readable report |
| Markdown | `.md` | GitHub-compatible markup |
| Comma-Separated | `.csv` | tabular data for analysis |
| HTML | `.html` | styled web report |
| JSON | `.json` | machine-readable structure (the repository's primary verdict format) |

**Graphics output:** PNG 600 DPI (screen and documents) + PDF/SVG (vector, publication).
Plot types: spinor-phase diagrams, eigenvalue landscapes, heatmaps of the 64 spinor
structures, QNM-frequency comparisons, deviation analyses, convergence diagrams, profiles
of the critical-collapse gauge (double nulls), zoom-chain and echo diagnostics, brick-ladder
clock curves and census maps, 3D/4D surfaces and their frame-by-frame evolution.

**Machine-readable verdicts.** Every campaign of the repository ends with a JSON file
that (a) fixes the full run configuration (seed, grid, BLAS pin, version), (b) is pinned
by pytest tests, (c) is the single source for the figures and tables. The data-table
rebuild is byte-exact deterministic (CHB: 13 tables; QHB: 31 tables, a SHA-256 registry,
exit 2 on drift).

<summary><b>Q: How does the "direct Einstein" differ from the monograph line?</b></summary>

**A:** The monograph line computes *spectral* invariants (the Klein quartic, the Dirac
operator) and builds corrections to them. The direct programme derives the *classical*
Einstein equations from the Hilbert action and evolves them numerically — without spinor
hypotheses; the spinor structure appears there only as a symbolic tower over the center
(the O1–O5 hierarchy) and is checked for compatibility with the data. Both lines converge
on the constant $b_{Ch}$ and the Δ·γ anchor.
</details>

<details>
<summary><b>Q: Why do the tests "pin" numbers instead of checking physics?</b></summary>

**A:** The pins are a regression contract: deterministic machines (BLAS = 1 thread, fixed
seeds) must reproduce the committed JSON to a given tolerance. Any deviation — a signal of
non-determinism, an environment change, or an error — fails CI. The physical statements
are checked not by tests but by machines (SymPy factorizations, Krawczyk interval
censuses, blind IVP audits); the tests only fix the verdicts.
</details>

<details>
<summary><b>Q: Which parts can be trusted, and which are hypotheses?</b></summary>

**A:** The layers of credibility: **(1) exact symbolic results** (SymPy in Q(√3)/Q(π),
Lean/Mathlib — theorems T1–T20, the pair clocks, the factorizations); **(2) deterministic
measurements** with budgets (A*, the floor, the echo, the QHB gap); **(3) literature
comparisons** (γ_Ch, Δ ≈ 3.44 — not fits); **(4) hypotheses** (the QNM factor, strong CP,
the septinial hypothesis) — always labelled and equipped with falsifiers. The registry is
in the [honesty ledger](#the-honesty-ledger-proven--confirmed--rejected--retracted).
</details>

## Glossary of programme terms

| Term | Meaning |
|---|---|
| **Septinial family** | the triple of spinor phases $\pi/2,\ \pi/3,\ \pi/7$ from which all correction quanta of the programme are derived |
| **Berry quantum / braking quantum** | the 1st and 2nd orders of the correction to the spectral level: $\beta(d)=d^2/2$ and $\alpha(d)=d^5/22$ |
| **Brick** | an independent choice of the spinor "brick" with phase $\delta_k=\pi/k$; the brick ladder δ₂…δ₁₄ |
| **Tick** | a finite-amplitude perturbation "tick" of the clock; its non-monotonicity in δ is an honest negative |
| **Book** | an algebraic relation between the tower variables (e.g. the UV and Mdef books); a "compensated book" is a consistent set |
| **The O1–O5 tower** | the hierarchy of central amplitudes derivable from the center equations; continued by the log-time τ-tower |
| **The clock τ\*** | the log-period of self-similarity (CSS) — the common cycle time; the subject of the clock-pair theorem |
| **Zoom / zoom machine** | regridding near the center that multiplies the effective resolution by the factor 2^z; z is the depth |
| **Echo Δ** | the log-period of the repetition of curvature spikes in the critical regime; the reference is 3.44±0.02 |
| **Floor** | the lower limit of the measurable mass on a fixed grid: $\lfloor M\rfloor\approx(13\pm1)/N$ |
| **Wall** | the principled limit of the zoom-machine depth; types: junk wall, v-budget, root floor |
| **Double nulls** | the characteristic coordinates (u, v) with the metric $ds^2=-\alpha^2du\,dv+r^2d\Omega^2$ |
| **CSS / DSS** | continuously / discretely self-similar solutions — the regime of critical collapse; DSS gives the echo periodicity |
| **Falsifier** | a one-line observation that would refute a statement; a mandatory field of every QHB claim |
| **Claim** | a registered statement of the QHB registry with a status (exact / measured-law / honest-negative / hypothesis / comparison) and a budget |
| **IVP** | Independent Verification Protocol — a blind check whose source of truth is outside the committed results (IVP-15 CHB, IVP-12 QHB) |
| **Iron-QA** | the QHB gates: check_json / check_numbers / check_release / check_lean_kernels — CI fails on any violation |
| **Closed kernel (Lean)** | a theorem proven in Lean 4/Mathlib without `sorry` and axioms; 18 kernels in total |
| **Twin** | an independent implementation of a package in another language computing the same control quantities |
| **ERRATUM** | a formal public retraction of an erroneous verdict in the honesty ledgers (5 retractions in the repository's history) |
| **Anchors, never fits** | the motto of the discipline: literature values are anchors for comparison, never fit targets |
