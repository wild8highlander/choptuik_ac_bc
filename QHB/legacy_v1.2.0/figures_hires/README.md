# figures_hires — the 600-dpi edition

The print-resolution edition of the committed architectures
(`scripts/hires_figures.py --all`).  Same data, same identity, 600 dpi,
including the extended architectures (per-sector responses, Lyapunov
panels, ensemble table, contact zooms) that do not ship at 300 dpi.

  (contact frequency vs mapped gap, per-branch honesty tags);
- `hq_19_anharmonic` — the C7 flux-tube sealing ladder + the V0*
  boundary collapse;
- `hq_20_pairwise_door` — the C8 pairwise door vs the linear door
