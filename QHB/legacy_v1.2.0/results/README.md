# results/ — the living ledger and the Evidence Engine

The one-page register of everything the package measured (RESULTS.md),
the roadmap (ROADMAP.md), the claims registry (CLAIMS.md + the machine
source claims_registry.json) and the audit trail.  Machine sources:
`campaigns/reference/*.json`, `data/qhb/*`.  The ledger is prose; the
verdicts are law; the registry separates the proven, the measured, the
compared and the hypothesised — build-pinned via `qhb/claims.py`.
