# Теория — класс моделей QHB

## 1. Объём и правила честности

Пакет изучает **размерно редуцированный класс моделей** («мостовой сектор»),
вдохновлённый двумя родителями: конфайнинг-сектором в духе Янга–Миллса с
координатой массового зазора Δ и термальным сектором, заякоренным классической
динамикой вихрей. Пакет никогда не выдаёт свои результаты за решёточную КХД;
каждое число принадлежит классу моделей и закреплено условиями нормировки ниже.
Утверждения разделены на пять статусов (см. RESULTS): exact, measured-law,
honest-negative, hypothesis, comparison.

## 2. Условия нормировки N1–N8

- **N1** вихревые единицы Γ = a = 1 ⇒ ω = 3/(2π) = 0.477464829275686…
- **N2** единицы зазора: дно долины C9 закреплено в β* = 3.3583,
  Δ_F,min = 0.181777; профиль долины квадратичен:
  Δ_F(β) = Δ_F,min + 0.35(β − β*)².
- **N3** наивный фальсификатор окна β_c = 2.9910 с измеренным отношением 6.3;

- **N4** обрез детектора E_max = 2.5 (за ним хвост не разрешён, T5).
- **N5** конфайнмент-бокс L_box = 12 (арефовский радиус бегства C11).
- **N6** космологическое сравнение η_B = 6.1e-10 (Planck 2018).
- **N7** статический барьер якоря V* = 0.9359375 (T13).
- **N8** seed: 20250918 / 777001 / 515003 / 902107 (pins в `qhb/pins.py`).

## 3. Сектор зазора (C1, C9, C12)

Конечнобъёмный зазор Δ_F(β, L) = Δ_F(β)·(1 − 0.35/L + 0.03/L²). Фазовая карта
9×41 показывает все 369 ячеек OPEN: в исследованном окне зазор нигде не
приближается к порогу детектора; утверждение конечнодиапазонное по построению.
Континуальный зазор — помеченная гипотеза (HYPO-CONT), никогда не заявление.

Асимметричный замок C12 моделирует сектор вещества возмущением η·U₁ с единичной
sup-нормой поверх потенциала зазора. Стоимость замыкания B₀ = Δ_F,min (N2).
Для любого профиля потеря барьера не превышает 2η (худший случай — ступенчатый
профиль), потому зазор выживает при всех η < η_crit = Δ_F,min/2 = 0.0908885 —
запас 1.49×10⁸ относительно η_B. Физически: барионная асимметрия на девять
порядков слишком мала, чтобы замкнуть зазор.

## 4. Струнный и термальный секторы (C2, C3, C7)

Закон Вильсона W = exp(−σRT) точен в классе; σ(β) = 0.25·(Δ/Δ_min)^1.5.
Мостовая температура несёт квантовые спин-поправки родительского проекта:
T_c = √σ/(2π)·(1 + (π²/8)β⁻² + (π⁵/704)β⁻⁴); коэффициенты проверены на 100
знаках. ВКБ-окно линейного барьера использует редуцированную координату с
эффективной массой m_eff = 1/2: S(E) = (2/(3σ))(σL − E)^{3/2}; окно закрыто
(T(0) = 9.21e-13 < 1e-12).

## 5. Вихревой якорь (C11)

Уравнения Кирхгофа для точечных вихрей с равными циркуляциями реализованы с
нуля. Равносторонний треугольник — относительное равновесие, вращающееся с
ω = 3/(2π). Спектр якобиана во вращающейся рамке {0, 0, ±iω, ±iω} с символьным
характеристическим полиномом λ²(4π²λ²+9)²/(16π⁴) — нейтральная устойчивость
(T11). При H < 0 движение ограничено с точным радиусом 2√I (T12); закреплённый
прогон измеряет r_max = 2.7654 при дрейфе инварианта < 1e-14. Якорная медленная
координата s несёт V(s) = V*·s²·e^{2−2s}, чей единственный максимум
V* = 0.9359375 sits точно при s = 1 (T13); все 300 траекторий имеют E < V* и
не убегают.

## 6. Свободные кварки (T15)

Комбинация T14 (постоянство зазора), T13 (якорный барьер) и T9 (закрытое
туннельное окно): у свободного цветового заряда нет допустимого канала
рождения в классе моделей. Наблюдательный маршрут тоже закрыт: если бы
свободные кварки существовали, они бы рассеивались, экранировали и заполняли
ямки зазора, образуя макроскопические накопления; игрушечная динамика
заполнения самотормозится (отрицательная обратная связь: заполнение поднимает
локальную стоимость замыкания), 0 насыщенных ям за 10⁶ шагов при η_B, тогда
как позитивный контроль при η = 0.5 > η_crit каскадирует. Комбинаторная
граница для объекта из 10³⁰ кварков — < 10^(−1.2×10³¹). Экспериментальные
поиски наггетов (n < ~1e-27 на нуклон) совместимы — только статус comparison.

## 7. Что изменило бы наше мнение

- Одна ячейка CLOSED в картах C9/C12 при допустимом η.
- Разрешённая форма хвоста за E_max (C4).
- Убегание с E < V* (C11) или Re λ ≠ 0 в спектре вихрей.
- Обнаружение наггета выше границы сравнения.
