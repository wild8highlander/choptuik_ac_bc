# Асимметричный замок (C12) — почему зазор вечен, а кварки не свободны

## 1. Физический вопрос

Поскольку вселенская асимметрия вещества и антивещества **полна** (антибарионы
отсутствуют в космологических масштабах; η_B = 6.1e-10, Planck 2018), история
конфайнмента имеет ещё одно требование согласованности: массовый зазор должен
выживать при любой допустимой perturbации из сектора вещества. Если бы зазор
мог замкнуться, свободные цветовые заряды распространялись бы, рассеивались в
квантовом поле, экранировали линейный потенциал и «заполняли бы щели» —
приводя к одиночным макроскопическим накоплениям кварков, которые не
наблюдаются.

## 2. T14 — асимметричный замок (exact)

Модель: потенциал зазора U₀ несёт стоимость замыкания B₀ = Δ_F,min = 0.181777
(N2); сектор вещества добавляет η·U₁ с sup-нормой ‖U₁‖∞ ≤ 1. Потеря барьера
U₁(0) − U₁(x*) ≤ 2 для любого профиля — худший случай (ступенчатый профиль)
достигает ровно 2. Отсюда:

    barrier(η) = B₀ − 2η > 0   ⇔   η < η_crit = Δ_F,min/2 = 0.0908885.

η-фазовая карта (41 лог-точка × 9 профилей) OPEN при всех η < η_crit и CLOSED
за ней — граница проходит точно через η_crit. Космологическое значение лежит на

    margin = η_crit / η_B = 148 997 540.98 ≈ 1.49×10⁸ (log₁₀ = 8.173),

то есть барионная асимметрия на девять порядков слишком мала, чтобы угрожать
зазору. SymPy проверяет худшее неравенство символьно (IVP-12).

## 3. T15 — свободных кварков нет (honest-negative + comparison)

Три независимых замыкания:

1. **Рождение**: туннельное окно закрыто — T(0) = 9.21e-13 < 1e-12 (T9);
   статический барьер якоря V* = 0.9359375 исключает классическое убегание при
   всех опробованных энергиях (T13, 0/300).
2. **Заполнение самотормозится**: свободные кварки экранировали бы и заполняли
   ямки зазора, но заполнение поднимает локальную стоимость замыкания
   (отрицательная обратная связь). Игрушечная динамика: 0 насыщенных ям за 10⁶
   шагов при η_B, тогда как позитивный контроль при η = 0.5 > η_crit
   каскадирует (100 ям насыщены).
3. **Комбинаторика**: даже при вероятности попытки T(0) ≈ 9.2e-13 макроскопический
   объект из N ~ 10³⁰ кварков имеет вероятность < 10^(−1.2×10³¹); даже 30
   одновременных кварков — 10^(−361).

Экспериментальные поиски наггетов ограничивают долю свободных кварков ниже
~1e-27 на нуклон — согласуется с предсказанием модели нуля (только статус
comparison, C12-EXP).

**Вывод**: при полной асимметрии вещества и антивещества зазор вечен внутри
класса моделей, и кварки не могут существовать как отдельные асимптотические
состояния. Наблюдаемый мир — только связанные адроны — вынужденный исход,
а не совпадение.

## 4. Что фальсифицировало бы замок

- Ячейка CLOSED при η ≤ η_B в карте C12.
- Разрешённый убегательный канал с T > 1e-12 при допустимых энергиях.
- Обнаружение наггета выше границы сравнения.
