# Фазовая карта C9 — зазор не замыкается (заявление конечного диапазона)

Метод: 9 объёмов (L = 6..32) × 41 связностей (β = 2.80..4.55, шаг 0.04375).
Статус OPEN, если Δ_F(β, L) > Δ_thresh = 0.0363485 (N3).

Результат: **369/369 ячеек OPEN**. Дно долины уточнено параболически до
(β*, Δ_F,min) = (3.3583, 0.181777) с кривизной 0.7 (точно для квадратичного
профиля). Долина внутренняя: зазор растёт в обе стороны.

Фальсификация наивного окна: экстраполятор узкого окна разведочного билда
предсказал замыкание при β_c = 2.9910. Прямой зонд измеряет
Δ_F(β_c) = 0.228995 = 6.3·Δ_thresh — фальсифицировано. Второй воспроизводимый
наивный экстраполятор (линейный МНК по правому флангу [3.6, 4.0]) предсказывает
корень β̂ = 2.9661 с измеренным отношением 6.48 — также фальсифицирован. Урок:
экстраполяция узкого окна через криволинейную долину порождает фантомные точки
замыкания.

Стресс-тест джекнайфа (глубокие проверки): удаление любых 3 точек вокруг
долины с последующим уточнением восстанавливает β* с точностью < 1e-9 —
уточнение не зависит от окрестности дна.

См. `data/c9_phase_grid.json`, `data/c9_valley.json`,
`data/c9_naive_falsifier.json`, фигуры `fig_phase_map_*`.
