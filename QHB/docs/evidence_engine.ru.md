# Evidence Engine — реестр из 30 утверждений

Каждое утверждение пакета живёт в `data/claims.json` с полями:

- **id** — стабильный идентификатор (реестр теорем T1–T15 + результаты кампаний
  - аудит);
- **status** — один из `exact`, `measured-law`, `honest-negative`, `hypothesis`,
  `comparison`;
- **statement** — зеркала RU и EN;
- **falsifier** — одно самое дешёвое наблюдение, которое убило бы утверждение;
- **budget** — пять полей: статистическая, систематическая, модельная,
  численная, внешняя неопределённость;
- **source** — указатели на кампанию и таблицы.

Статусы (v1.3.0): exact ×7, measured-law ×12, honest-negative ×9,
hypothesis ×1, comparison ×1.

Правила дизайна:

1. Утверждение без фальсификатора не допускается.
2. Гипотезы хранятся, но никогда не цитируются как результаты.
3. Внешние значения (η_B Планка, границы поисков наггетов) — только comparison:
   они могут поддержать согласованность, но не саму модель.
4. Честные негативы — полноценные результаты: неразрешённый хвост (T5), бегство
   свободных трёх тел (T6), внеоконная невалидность (C10-NEG), отсутствие
   недетерминизма (DETERM) и невозможность свободных кварков (T15) — всё это
   сформулировано как негативы.

Аудит IVP-12 (12/12 PASS) — точный каркас: у каждого ключевого числа есть
независимый второй вывод (символьный, 100-значный, квадратурный или
алгоритмический). См. `data/audit_ivp12.json` и `docs/theory.ru.md` §7 о политике
фальсификации.
