# Code of Conduct

## Our standard

The Quark-Hawking Bridge project is built on a falsification-first discipline:
claims are stated with falsifiers, numbers carry uncertainty budgets, and
negative results are reported honestly. Discussion here must meet the same
standard.

## Expected behaviour

- Attack claims, not people. "This kernel is wrong because X" beats any adjective.
- State falsifiers. A critique without a checkable consequence is welcome as a
  question, not as an audit.
- Quote the machine layer. If a JSON artifact contradicts prose, cite the file.
- Respect honest negatives. A refused upgrade of a status (`exact`) is a
  feature of the project, not an obstacle.

## Unacceptable behaviour

- Harassment, personal attacks, or discrimination of any kind.
- Publishing others' private information without consent.
- Deliberately injecting unverifiable numbers into data or prose.

## Enforcement

Maintainers may remove comments, issues, or PRs violating this code and may
ban repeat offenders. Reports: open a private advisory or contact the
maintainers directly.
