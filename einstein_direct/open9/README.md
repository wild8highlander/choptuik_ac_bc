# OPEN9 + v20 + v21 + v22 — машинное закрытие девяти открытых вопросов

**EN.** This folder is the self-contained closure package for the nine open
questions of the verification monograph (Chapter 7) plus the two follow-up
campaigns v20a/v20b. Everything here is deterministic, single-threaded
(BLAS pinned to 1), offline wherever saved JSONs suffice, and re-runnable
**from this folder alone** — the machines carry a private copy of
`results/` so no repo paths are needed.

**RU.** Папка — самодостаточный пакет закрытия девяти открытых вопросов
монографии верификации (глава 7) и двух последующих кампаний v20a/v20b.
Всё детерминировано, однопоточно (BLAS = 1), офлайн там, где хватает
сохранённых JSON, и перезапускаемо **из одной этой папки** — машины несут
приватную копию `results/`, пути репо не нужны.

## Состав / Layout

| 7 | 1/r-мода | `m1_tracker.py` | \|M1\| УБЫВАЕТ по зумам (1e-8 → 1e-20): мусорный пол, растущей 1/r-моды нет на доступной глубине; слово ворот для №3 |

## v20 — продолжение к уровню измерения / follow-up to the measurement level

| Кампания | Машина | Вердикт |
|---|---|---|
| v20a (№2) | `amplitude_ladder.py` | лестница eps ∈ {3e-3..1e-4} исполнена на PDE-машине: эхо-поезда нет (0–3 пика, стоп singularity/v_exhausted, z ≤ 4.6); то же во ВСЕХ сохранённых кампаниях (z ≤ 6.05) — показатель p НЕ измеряем на текущей машине; фальсифицируемый дискриминатор (p = 1/2 / 1 / 2) и дешёвая ступень (~15–20 c) записаны для v21 |
| v20b (№3) | `depth_z30.py` | [D1] линейный сектор сертифицирован до z = 30 в замкнутой форме (Π = I + B·T, фаза ТОЧНО 0, светской рост ~126); [D2] бюджет пола S_req(30) = e^{γ·20.65} ≈ 2.26e3 (×10 запас), 41 спинорное эхо; [D3] замкнутая петля: при S = S_req(z) априорное правило даёт процентную γ/Δ (5/5), наивный ОЛС у стены воспроизводит провал q3 (−23%); [D4] протокол v21 |
| v21 (№2/№3/№4) | `deep_echo_v21.py` | протокол раздела 5 ИСПОЛНЕН: гейт q7 на активных строках (калибровка прогоном 0: рестарт-строки вакуумны), откат+уплотнение, чекпоинты; ГЛАВНЫЙ ФАКТ [D-v21]: стена глубины чувствительна к оконной политике — z(w=5) = 1.78 → z(w=3) = 7.20 (глубже всех сохранённых кампаний) при 0 инвазий, следующая стена — v-бюджет; бюджет S_req(30) ≈ 5.0e3 от достигнутой стены; лестница вторым проходом (3e-3/1e-3/1e-4): ≤ 3 пика — p не измерим, дискриминатор сохранён |
| v22 (№3 — стена) | `deep_echo_v22.py` | диагноз стены w = 3 (цепочка v21 воспроизведена с расхождением 0): [F1] телескопический кап не связан (4/4); [F2] финальная стадия — вакуум (лестница триггеров СПУСКАЕТСЯ по v, окно смотрит вперёд); [F3] v-extension мёртв по построению (запас 0.0 точно); [F4] ratchet покрытия — пол окна может только подниматься; зонды: v_ahead инертен, глобальный/поздний якорь разрушителен/зажат; [C2c] КОРНЕВОЙ якорь (k1 = 0.52-0.60 на зуме 1) + якорь на пол покрытия СРЫВАЮТ стену: z-рекорд 8.56 (+19% к 7.20), 4-й пик ДОСТИГНУТ (7 пиков, 4 на стадии); Δ_eff = 0.611 ± 0.446 ≠ DSS 3.44 (исключена на 6.3σ) — периодичность честно НЕ подтверждена; новая стена — корневой пол |

## Запуск / How to run

```bash
cd open9
python3 -m pytest tests/test_open9_standalone.py -q   # 9 passed, ~3 c
cd machines
python3 depth_z30.py            # ~1 мин
python3 amplitude_ladder.py     # ~1-2 мин (4 PDE-ступени)
# и любые из 9 машин q1..q9 (каждая <= 10 c)
```

Полная верификация в корне репо: `python3 -m pytest tests/ -q` → **58 tests**
(21 core + 22 OPEN9 + 4 v20 + 5 v21 + 6 v22).
