# einstein_direct — прямое решение задачи Чоптюка из классических уравнений Эйнштейна

**Подробная документация — в [README_EN.md](README_EN.md) (14 разделов, английский).**

Кратко о модуле:

- **Машинный вывод** (SymPy + mpmath 50 знаков): действие Гильберта →
  уравнения Эйнштейна в 1+1 двойных нулевых координатах; верификация на
  точном решении Робертса–Оширо, невязки ~10⁻⁴¹ (все 5 связей).
- **Солвер**: характеристический марш (РК2-Хойн), 2-й порядок; плоское
  пространство 10⁻¹⁴; 5/5 регрессионных тестов.
- **Фиксированная сетка**: бисекция A* = 0.0805333 (N=1600); честный
  негативный результат по γ (массовый пол M ≈ 4·du при нуклеации горизонта).
- **Зум-машина v2/v3.2**: цепочка перерегрирований до z ≈ 5.9 (4 зума);
  v3.2 — регулярное замыкание центра (спинорная E/O-декомпозиция, связка
  наклонов s₁−t₁ = −2a, кубическая масса, проекция парностей); массовый
  мусор подавлен (3.56 → 6.6·10⁻⁵); стена глубины задокументирована.
- **Спинор-анализ (π/15, π/30)**: Z₂-зеркальные парности центра (A/B:
  клэмп 1.00 → regular 0.35 по чётной добавке p+q); соотношения фреймворка
  R1–R4, включая компенсацию в произведении γ·Δ до 0.04%; предсказание
  ω = 120/7; честные пределы данных (нужно z ≥ 30 — см. README_EN §11).

## v5: центральный Тейлор-патч (сессия 5)

Фундаментальный уровень выполнен: иерархия центра выведена МАШИННО
(`sympy_center.py`) и верифицирована SymPy (ОДУ O1–O5: связки чётной E-моды
и нечётной спинорной O-моды; форма O3 содержит член +W2, пропущенный ручным
выводом, форма O5 — коэффициент 2 при (R3·R1'/R1²)·P0'). Численные невязки
конвейера на подкритическом забеге: O2 ≈ 1.1e-3, O1 ≈ 2.8e-2.

Патч `center_closure="taylor"`: t0/d0 эволюционируют по ОДУ как внутреннее
ГУ (Чоптюк-1993), зона пересобирается из ряда (E(0) = t0 — эволюционирующая
величина), чётная паразита (p+q) проектируется с учётом смещения центра x*,
все фиты — с санитарными guards. p,q,r,alpha2 не трогаются (дискретная C1).

Итог честно: мусор массы у центра 2.9e-6; глубина цепочки до z = 7.19

центра в зеркальную асимметрию сырого марша вне зоны + хрупкий захват
горизонта (дорожная карта v6 — в README_EN.md §15 и

## v8: гексагональный Пуанкаре-цикл трансформаций (динамика вместо усечённой башни)

O6-вердикт сессии 8: ветвь UV[ξ³] форсирует T0² = 9/4 (τ₃ = (3/2)²), ветвь
Mdef[ξ⁵] — T0² = 9/16 (τ₅ = (3/4)²), вместе — только тривиальное R3 = 0: у
усечённой башни нет точного CSS-решения, источники принципиально динамичны.
`sympy_hexcycle.py` формализует ответ: вместо статического усечения —
динамический цикл шести станций (пирамида → конус → усечённый конус →
параболический пивот → чаша → лог-замыкание → пирамида) по уравнениям
Пуанкаре в квазискоростях на C₆-циферблате формы. Две несовместные ветви
становятся шагами двух РАЗНЫХ книг цикла:

- **амплитудная книга**: CORE-пара (3/2)² = τ₃, кольцевые пары (4/3)² = 1/τ₅,
  полный цикл κ_cyc = ln(τ₃/τ₅²) = ln(64/9) = 1.9617 против якоря
  κ_obs = Δ_sp/γ = 1.9600 (+0.085%); дефицит замороженной башни
  λ₊(27/80) = 1.5091 (+0.451 в κ) заполнен циклом на 100.4%;
- **часы эха**: −ln τ₅ = ln(16/9) за сторону гексагона, Δ_cyc = 6 ln(16/9) =
  12 ln(4/3) = 24 ln(2/√3) = 3.4522 против Δ = 3.44 (Чоптюк, 1993; внутри
  коридора ±0.02);
- **«6-угольные лог-вычисления» — точная геометрия**: шаг кольца 4/3 = (2/√3)²
  — квадрат отношения радиусов описанной/вписанной окружностей гексагона;
  ветви O6 сами квадраты (√τ₃ = 3/2, √τ₅ = 3/4, отношение 2 — удвоение
  пирамиды);
- **γ_cyc = Δ_sp/κ_cyc = 0.373683** (γ_lit = 0.374, −0.085%; b_Ch −0.75%);
- **аттрактор — предельный цикл (DSS, а не CSS)**: форма на сечении
  возвращается в пирамиду точно (ошибка 0), масштаб падает в e^Δ ≈ 31.6 за
  цикл — структурное объяснение наблюдения Чоптюка.

Машина: 15/15 символьных тождеств; уравнения Пуанкаре = Эйлера–Лагранжа
(абелева группа циферблата), запирание V'(kπ/3) = 0 всех шести станций,
p_θ = const в свободной циркуляции; период свободной циркуляции = Δ_cyc
точно (<10⁻¹²), запертой (V₆ = 0.05) — +0.253% (честный O(V₆)-эффект); шаг
книги измерен численно до 10⁻⁹. Аксиомы (разбиение 2+4, глобальные часы) и
ограничения — сформулированы честно (README_EN §18). Отчёты:
`hexcycle_report_ru.pdf` / `hexcycle_report_en.pdf`; рисунки RU/EN 300 dpi

## P4-замыкание (O6+): цикл форм в уравнениях Эйнштейна и Гильберта (сессия 11)

Машина: `sympy_p4_einstein_hilbert.py` -> `results/p4_einstein_hilbert.json`.

- **Как цикл живёт в классических уравнениях**: остатки double-null ЕСТЬ
  `G = κT` с точными факторами: `G_uu − κT_uu = −(2/r)·C1-форма`,
  `G_vv − κT_vv = −(2/r)·C2-форма`, `G_uv = −(2/r)·(UV + r(TH − st))`;
  `T_uv ≡ 0` (нуль-нуль сектор тензора Гильберта пуст); тождество Гильберта
  `∇_μT^μ_ν = (□Φ)∇_νΦ` — динамика источников и есть закон сохранения.
  Шесть станций цикла — режимы ОДНОГО тензора.
- **Кольцо и часы выведены**: ядро O1-O5 даёт `W2h = (4/3)T0²R1h` (кольцо
  `4/3 = (2/√3)²`) и `P2h = T0/3` (часы) — машина выводит, не постулирует.
- **Аудит точки session 8**: вторые производные источников (W2'', R3'', P4'')
  и R5' молча обнулялись; в исправленной системе ветви 9/4 и 9/16 сливаются
  в общий корень **τ\* = 27/4** — замороженная CSS-точка O6-башни существует
  (уникальна); двухкнижная конструкция `κ_cyc = ln(64/9)` опиралась на артефакт.
  В τ\* = 27/4: `T0h = 3√3/2`, `P2h = √3/2 = sin(π/3)` — гексагональное
  отношение появляется само; спектр λ⁺(27/4) ≈ 8 — точка не аттрактор.
- **Пролонгация O7**: сохранение ядра вдоль потока убивает адиабатические
  динамические точки (V1/V2 нарушают, V3 замкнута только на замороженной);
  подлинная динамика источников требует вторых потоков — предельный цикл (DSS).
- **Чистое d-поле**: `c ↔ d` при зеркале, `(d−c) = ω_ξ = 2W2ξ` нечётно;
  экстрактор `[(d−c)(ξ) − (d−c)(−ξ)]/(4ξ)` гасит чётный мусор точно;
  v8-пары асимметричны (leak 0.92) — каналу W2/t0² нужны зеркальные пары (v9).

Файлы: `sympy_p4_einstein_hilbert.py`, `results/p4_einstein_hilbert.json`.
Запуск: `python3 sympy_p4_einstein_hilbert.py` (~15 с).

## v11: три поправки репозитория (b-C, a-C, a-B) в башнях (сессия 15)

Машина: `sympy_spinor_corrections.py` -> `results/spinor_corrections.json`.

**Вопрос автора.** Может, в уравнениях Эйнштейна есть «ошибка», требующая
выправления ради замыкания на π/30, — и настоящая причина в том, что мы
сознательно не встраивали три вычисленные поправки репозитория (b-C Бэрри,
a-C торможение, a-B) как естественные функции и формулы. Исправят ли они
башни?

**(0) Поправки как точные функции (кросс-чек по монографии OK).**
Фазы Γ(2,3,7): δ_A = π/2, δ_B = π/3, δ_C = π/7. Бэрри β(δ) = δ²/2,
торможение α(δ) = δ⁵/22 (k = b₂(K3) = 22): bC = π²/98 = 0.100710,
aC = 8.2763e-4 (≈1/1200), aB = (π/3)⁵/22 = 0.057243.

**(1) Аудит дверей: «ошибки» нет — есть СТРУКТУРА.**
С поканальными связями (κ_C1 в C1: (κ/2)rs², κ_C2 в C2: (κ/2)rt², κ_TH в TH:
(κ/2)st) символьная пересборка показывает: SC/UV/Mdef БЕЗ κ (утечек ноль —
ремонтировать нечего); карта каналов точная; **связка кольца** (новая
машинная теорема): C1-невязки в точке цепочки обнуляются ⟺ **κ_C1 = κ_C2**;
**связка ветвей**: UV_xi3 = −2T0h²(8κ₂²T0h² − 93κ₂ − 15κ_T) и
Mdef_xi5 = −2T0h²(4κ₂²T0h² − 39κ₂ − 15κ_T) имеют общий положительный корень
⟺ **κ_C2 = κ_T** (разность 15(κ₂−κ_T)/(8κ₂²)).

**Следствие: голономная поправка может править башню ТОЛЬКО как РАВНОМЕРНАЯ
перенормировка κ → κ_hol во всех трёх каналах.** Асимметричное встраивание
(a-B только в C1) убивает CSS-точку: C1-невязка 0.386 (машинная
демонстрация). Это предсказание башни о допустимой форме поправок.

**(2) Исправленное семейство ТОЧНО: `τ*(κ) = 27/(2κ)`.**
При равномерной перенормировке точка существует при любом κ > 0:
T0h² = 27/(2κ) (неисправленная точка — член κ = 2); **лестница станций
голономно-инвариантна** (R3h = 3/2, W2h = 9, R5h = 183/40, M5h = −105/4,
массовая связка M3*/R1* = 9/2, часы P2h/T0h = 1/3 — всё без κ); двигаются
само основание τ*, P2h = T0h/3, P4h ~ κ^{−1/2} и отношения к T0h²:
**кольцо W2h/T0h² = 2κ/3** (4/3 — член κ = 2; цель v9 становится
2κ_hol/3), R3h/T0h² = κ/9. Книга: ln τ* = ln(27/(2κ)).

(p, n) ∈ {0,1,2,4}×{1,2,3}; в частности cₙ,ₙ = 1 для ВСЕХ (n, p):
**выбор «коэффициент 1» dd-слотов (сеанс 17, заимствованный из прецедента
ddQ) теперь ВЫВЕДЕН, а не заимствован.**

  линейный остаток монодромии.**

### Вердикт сеанса

(a) паттерн (λ+a)(λ+b)(λ+c)F обобщается ТОЧНО (весовое правило); таблицы
третьего порядка существуют и верифицированы — и не добавляют ничего в
линейный спектр (пролонгационная инвариантность); (b) независимый закон dd
СУЩЕСТВУЕТ и ВЫНУЖДЕН: пролонгационное замыкание — единственное решение
выведенного из тождеств сохранения ограничений (ранг Uk = 9), альтернативы
вырождены машинными фактами, подгонки нет нигде; (c) δ_mono теперь
ИЗМЕРЕН, а не только выведен: 0 с честными границами (рост ~1e−13, фаза
~1e−7 за эхо — фазовая граница задаётся полом дефектности). **Остаток
«барионной асимметрии» башни — конечно-амплитудный феномен: весь линейный
мир (статика + де-адиабатизованные вторые потоки + третьий порядок)
аннигилирует точно. Следующая кампания: нелинейный марш DAE.**

Запуск: `python3 sympy_third_order.py`, `python3 sympy_dd_closure.py`
(экспорт .npy нужен для (c)), `python3 march_delta_mono.py`.

## v15: нелинейный марш DAE — множество решений через критическую точку это плоская линия (сессия 19)

**Вопрос (вердикт v14).** Весь линейный мир аннигилирует точно; остаток
«барионной асимметрии» (зазор фантомов ~2.9% к π/30, δ_mono) объявлен
конечно-амплитудным феноменом. Порождает ли его конечная амплитуда? Для
ответа построен нелинейный марш DAE — интегрирование полной нелинейной
системы при конечной амплитуде.

### Машина (`dae_nonlinear_core.py`)

Полная система строится символьно и ламбдифицируется (сборка ~8 с, вычисление
0.08 мс, кросс-чек ламбдифицированных якобианов с точными матрицами сеанса 17
rel ~1e−15): ограничения F(x) = 0 (18 ур.); замыкание — ТОЧНОЕ нелинейное
обобщение пролонгации 18b (цепное правило dF/dτ = Ja(x)a′ + Jv(x)v′ +
J2(x)dd′ = 0 без линеаризации, те же 9 неизвестных); совместность r(x) = 0 —
нелинейный аналог скрытых условий (выровненное левое ядро Uk, норма
базис-инвариантна); RK4 (dt = 2e-3), min-norm Ньютон-проекции на {F=0} и
{r=0}, мониторинг ранга/невязки/дрейфа.

### Машинные теоремы (обе точки κ = 2 и 2 − π²/98)

- ранг DF(x*) = 14 (вырожденность 18b), но на конечной амплитуде 15 — x* —
  ОСОБАЯ точка множества ограничений;
- **[T1] ПЛОСКАЯ ЛИНИЯ.** Направление ker B — a-чистое (v = dd = 0 точно;
  ход R1h–R3h–R5h–M5h по цепочке) и несёт F = 0, r = 0, V = 0 ТОЧНО (машинный
  нуль до радиуса ~26) — линия ТОЧНЫХ равновесий нелинейной DAE; марш 8 эхов
  с неё: дрейф 0 (baseline) / 8.6e−12 (one-brick).
- **[T2] СТАТИКА S = {F=0} ∩ {r=0}.** (а) M2-направление e2 НЕ касается S:
  кокоядро-невязка |P_coker G(x*+h·e2)|/|G| КОНСТАНТНА по h (0.058 baseline,
  5.9e−4 one-brick — нет O(h)-распада, C²-ветвь невозможна); совместный
  Ньютон из e2-точки коллапсирует к x*/линии (0.265 → 0.081). (б) НО в
  нуль-множестве есть ВТОРОЕ направление b2, на 97–99% равное t3 —
  направлению, убитому ЛИНЕЙНЫМ level-3 анализом 18b! b2-ветвь существует
  СТАТИЧЕСКИ: joint-Ньютон держит радиус (×1.03–1.04), |F|, |r| ~ 1e−14 на
  всех амплитудах до |x − x*| ≈ 1.35.
- **[T3] ПОТОК НА ВЕТВЯХ.** На линии V = 0. С b2-ветви замыкание совместимо
  В точке (r ~ 1e−14), но поток немедленно ПОКИДАЕТ S: level-3 сход
  |Dr(x0)·V(x0)| = (39.2 ± 0.2)·A в ОБЕИХ точках (линеен по A), срыв
  замыкания на первой стадии RK4 — b2-ветвь решений НЕ несёт.

### Вердикт

**Единственное многообразие решений нелинейной де-адиабатизованной DAE через
критическую точку — плоская линия равновесий. Нелинейный марш вне линии
невозможен АЛГЕБРАИЧЕСКИ — множество согласованных нестационарных начальных
данных конечной амплитуды пусто (e2 — статически, b2 — динамически), — а не
численно. Линейная динамика M2 (нильпотентный Йордан-2, светской дрейф,
δ_mono = 0) — артефакт линеаризации: она не линеаризует никакого нелинейного
потока. Аннигиляция «барионной асимметрии» продолжается на нелинейный
уровень: выведенная (не подогнанная) динамика вторых потоков НЕ производит
конечно-амплитудного остатка в окрестности критической точки.**

Честные оговорки: (i) Пюизо-ветви (не-C²) не исключены; (ii) глобальные
компоненты S вдали от x* не искались (стрельба/nsolve — следующая кампания);
(iii) жёсткость — свойство усечённой башни с выведенным dd-законом (весовое
правило); полная PDE-машина (v6–v9) остаётся носителем физики эха.

Запуск: `python3 march_dae_nonlinear.py` (нужен `dae_nonlinear_core.py` и
экспорты `.npy` v14; ~55 с) → `results/march_dae_nonlinear.json`.

## v16: HEXCYCLE-DAE — цикл фигур как глобальный предиктор (сессия 20)

**Вопрос (вердикт v15 + предложение автора).** v15 доказал, что локальный марш
DAE около x* алгебраически невозможен (единственное многообразие решений через
критическую точку — плоская линия равновесий) и оставил оговорку: *глобальные
компоненты S вдали от x* не искались*. Предложено использовать сам динамический
геометрический цикл — пирамида → конус → усечённый конус → параболический
пивот → чаша → лог-замыкание (`sympy_hexcycle.py`) — как ГЛОБАЛЬНЫЙ предиктор:
маршрут конечной амплитуды через фигуры.

### Вложение (аксиомы E1–E3, все помечены, без подгонки)

- **E1 (амплитудная книга).** Масштаб T0h двигается шагами цикла:
  T0h_k = T0h*·exp(∓r_k), r_k = Σ STEPS — парные замыкания (3/2)² = τ3 = 9/4
  (CORE, UV[ξ³]) и (4/3)² = 1/τ5 = 16/9 (RING, Mdef[ξ⁵]) — собственные числа
  лестницы машины; станция 0 (пирамида) = критический масштаб; имена станций
  циклятся с периодом 6.
- **E2 (линейка).** Чистая книга держит R1h = 1; компенсация линейки
  тестируется отдельно (T1c/T1d).
- **E3 (цепочка + кинематика).** Амплитуды — точные chain-формы v15
  (D0h ≡ 0 проверено); гомотетическая ходьба: τ = T0h², dT0h/dτ = 1/(2T0h),
  потоки/dd — точное цепное правило.

### Машинные факты (обе точки κ = 2 и 2 − π²/98)

- **[T1a] Чистая книга статически НЕ точна.** F(chain(T0h_k, 1), 0, 0) доходит
  до 2.7e1 (коллапс, 13 станций) и 2.7e5 (обдув); худшие уравнения {0, 2}
  (baseline) / {2, 6} (one-brick). Станция 0 = x* точно (якорь).
- **[T1b] Полюс P4h — МЯГКИЙ.** Chain-форма P4h имеет подлинный полюс при
  τ = 45/8 = 5.625 (baseline; T0h = 3√10/4 ≈ 2.3717 — внутри первой же
  кольцевой стороны коллапсной ходьбы); в one-brick точке полюс СДВИГАЕТСЯ к
  τ ≈ 5.923. Мультистарт-Ньютон со свободными амплитудами на масштабе полюса
  даёт F ~ 1e−15: статическая ветвь ПРОХОДИТ через масштаб полюса — полюс
  артефакт решённого представления цепочки, а не барьер книги.
- **[T1c] КОМПЕНСИРОВАННАЯ КНИГА СУЩЕСТВУЕТ — глобальные статические
  компоненты S.** Посадки минимальной коррекции (min-norm Ньютон из чистой
  книги, T0h приколот, дегенератный угол R1h → 0 с R3h = R5h = M5h = 0
  отбракован) сходятся на ВСЕХ масштабах книги: 12/12 коллапс + 6/6 обдув в
  обеих точках. **32 компенсированных состояния имеют F = 0 И r = 0** (r ≡ 0
  на статическом срезе, проверено): первые ГЛОБАЛЬНЫЕ компоненты
  S = {F=0} ∩ {r=0} вдали от x* — оговорка v15 закрыта. Локальная
  размерность статического множества при приколотом масштабе 0–1.
- **Запертая линейка.** В коллапсе R1h(k) проваливается на кольцевых станциях
  (минимум 0.687 на масштабе усечённого конуса) и РАССЛАБЛЯЕТСЯ обратно к 1
  (0.9997 к станции 12); дефект возврата за цикл δ_R1h = 0.064; провал НЕ
  повторяется во втором цикле (max |R1h(k+6) − R1h(k)| = 0.31 — транзиент,
  выборка зависит от пути Ньютона). В обдуве выборка сползает к
  близ-дегенератному углу (R1h ~ 0.056–0.1) — полубашня притягивает обдувную
  книгу (интерпретационная асимметрия, помечена).
- **[T1d] Компенсация на цепочке невозможна.** Скан R1h при фиксированных
  chain-амплитудах: остаток убывает только к дегенератному углу (R1h → 0,
  остаток ∝ R1h³) — невырожденная компенсация обязательно сходит с
  многообразия цепочки.
- **[T2] Кинетический слой аннигилирует.** Пролонгация гомотетической ходьбы
  точна ПО ПОСТРОЕНИЮ (≤ 1.2e−13), но замыкание с ней несовместимо:
  r_max = 2.1/9.7 (baseline коллапс/обдув), 1.6/8.3 (one-brick); срывы
  замыкания на всех кинетических станциях (7/7). Гомотетическая ходьба по
  книге — НЕ решение DAE.
- **[T3] Глобальная стрельба.** Свободные совместные посадки [F; r]: 14/24
  сошлись; каждая точка с |V| > 1e−3 имеет exit_rate 62…8e5 — поток
  немедленно покидает S (вердикт v15 T3 продолжается глобально); точки с
  малым |V| (1e−8…1e−4) — пыл равновесий (exit ~ 1e−14…1e−10). Полы
  посадок с приколотым T0h ~ 10 — stalled-артефакт, перекрыт [T1c]
  (статические компенсированные состояния лежат в S с приколотым T0h).

### Вердикт

**Фигуры несут СОСТОЯНИЯ, но не ДВИЖЕНИЕ.** Статически цикл форм встраивается
в выведенную нелинейную DAE: компенсированная книга — семейство CSS-подобных
равновесий, покрывающее все масштабы книги, — первые глобальные компоненты S
вдали от x* (оговорка v15 закрыта). Динамически цикл аннигилирует: замыкание
несовместимо с ходьбой (r ≠ 0), и каждая точка S с конечной |V| мгновенно
покидает S (exit-тест). Динамика эха/цикла остаётся за PDE-машиной (v6–v9);
цикл фигур служит статическим хребтом + книгами (κ_cyc = ln(64/9),
Δ_cyc = 6 ln(16/9)), уже установленными в модели гексцикла.

Оговорки: выбор среди статического веера зависит от пути Ньютона (min-norm из
чистой книги каноничен, но не единствен); прыжки ветвей у мягкого полюса не
исключены; E1–E3 — аксиомы; профили фигур (тент/парабола/чаша) остаются слоем
визуализации модели — в DAE цикл входит через свои книги (шаги/зоны/станции).

точках — кирпичная зависимость препятствия тика кандидат на отдельную

## v18: BRICK-LADDER-TICK + GLOBAL-STATIC-SEARCH — промежуточные кирпичи и исчерпывающая перепись статики (сессия 22)

Директива автора: **(а)** кампания с промежуточными кирпичами —
зависимость препятствия тика от δ (намеченный кандидат v17 [C3]);
**(б)** глобальный поиск недегенератных статических ветвей
(nsolve/стрельба вне книжных стартов — оговорка v15/v17). Две машины:
`brick_scan_tick.py` и `global_static_search.py`.

### (а) Лестница кирпичей `brick_scan_tick.py` [B1]–[B5]

Кирпич = бэрри-фаза δ с аддитивным скринингом κ(δ) = 2 − δ²/2 (записанное
соглашение v11). Лестница: δ_k = π/k, k ∈ {2,…,12,14} + baseline (δ = 0) —
12 точек.

- **[B2] Теорема о паре часов на лестнице (точно, SymPy).** На **12/12
  кирпичах** GCD(UV_xi3, Mdef_xi5) на цепочке имеет **единственный общий
  положительный корень** τ*(δ) = 27/(2 − δ²) с **точным нулём** в нём:
  27/4 (baseline) → 17.617 (k=2) → 7.108 (k=7, выживший) → 6.836 (k=14).
  Пара часов непрерывно двигается кирпичом по всей лестнице — обобщение
  [C1] v17 с двух точек на весь кирпичный ряд.
- **[B1] Плоская линия v15 T1 не зависит от кирпича:** R1h-линия при
  критическом масштабе T0h*(δ) статична (F ≤ 1e−7) на 12/12 кирпичах.
- **[B3] Препятствие тика от δ (главная наблюдаемая).** ERRATUM к методу
  [C3] v17: `r_max = max|W·res18|` — базис-зависимая величина
  (W_align мутирует Procrustes-продолжением rvec), абсолютные числа [C3]
  v17 были история-зависимыми. Здесь — **исторически-свободная мера
  ‖r‖ в замороженном базисе x\*** + робастность по всем 5
  кернел-направлениям (траектория project_Fr инвариантна). Результат:
  **зависимость существует, немонотонна и не степенная** (log-log наклон
  +0.65 с невязкой ln 2.1 по 11 кирпичам; от ‖r‖ = 0.005 при k=12 до
  0.16 при k=8, кик 0.05). **Выживший кирпич δ_C = π/7 НЕ является
  минимумом препятствия** (минимум k=12) — тик не селектирует кирпич.
  Относительный якорь v17 держится на инвариантной мере: one-brick
  ‖r‖ = 0.032 < baseline 0.043 (кик 0.05); 0.029 < 0.107 (кик 0.01).
- **[B4] Фантомный зазор по лестнице.** Скан карандаша в исправленных
  точках: лучший hit **+1.139% к π/30 при δ = π/3** (baseline +3.10%,
  one-brick +2.88%); **внутри 1% ничего** (0 попаданий из 12) — скан
  замыкания π/30 не находит (multiple-testing оговорка).
- **[B5] Дефект книги κ-независим:** F_static_max = 26.79 на всех 12
  кирпичах (те же 24 масштаба первого цикла) — дефект живёт в κ-свободной
  части уравнений (согласуется с v11: SC/UV/Mdef без утечек κ).

### (б) Глобальная перепись статики `global_static_search.py` [G0]–[G3]

Известные семейства: S0 тривиальная, S1 x\*, S2 плоская линия v15 T1,
S3 полубашня. Обе точки (baseline, one-brick).

- **[G1a] ТЕОРЕМА ФАКТОРИЗАЦИИ (точно, SymPy) — перепись на цепочке
  исчерпывающая.** После цепочных подстановок rest-система — всего ДВА
  уравнения, и они факторизуются: Mdef_xi5 = −8R1h²T0h²(4T0h²−27)/27,
  **UV_xi3 = 2·R1h·Mdef_xi5 точно** (one-brick: тот же вид с часами
  (196−π²)T0h²−1323); остальные три rest-уравнения (C1_xi1..3) vanish
  тождественно. Значит **S ∩ цепочка = {R1h = 0} ∪ {T0h = 0} ∪
  {T0h = T0h\*} ТОЧНО** — полубашня точная (не предел), тривиальная
  линия точная, плоская линия единственная недегенератная. «Пара часов»
  — это ОДНО часовое уравнение в двух ветвях с разными степенями R1h —
  машинная причина, почему GCD-теорема v17 даёт единственные часы.
- **[G1] Численная перепись подтверждает:** 2D-скан 2501 ячейка
  (T0h·10^[−4.5,1.5] × 10^[−2.3,1.7]) + мультистарт Гаусс-Ньютон (56
  сидов): все корни — в трёх семействах, **новых 0** (полный F-чек).
- **[G2] Внецепочечный свободный Ньютон** (8 амплитуд, без пина, 300
  случайных стартов в широкой коробке с возмущёнными цепочными
  амплитудами): захваты плоской линией 34, тривиальные уходы ~165,
  не приземлились ~100 (лучший неприземлившийся F = 4.4e−13 —
  застревание на жёсткости), **новых кандидатов 0**.
- **[G3] Стрельба/продолжение от x\*:** статический кернел dF/da в x\*
  **1-мерен** (только касательная плоской линии) — других статических
  направлений из x\* не выходит; вдоль линии 4–7 провалов ранга
  (кандидаты ветвления) — попытки ветвления (Ньютон с пином T0h из
  x_line ± ε·w) **не дают ни одной посадки вне линии**.

### Вердикт

**Статическая структура башни исчерпана точно: S ∩ цепочка — ровно три
семейства (тривиальная, плоская линия при критическом масштабе,
полубашня), недегенератных статических ветвей вне критического масштаба
НЕТ — ни на цепочке (точная факторизация), ни вне её (численная
перепись: 300 стартов + кернел-анализ).** Динамика (живые часы) —
исключительно за PDE-машиной v6–v9. По кирпичам: часы пары
τ*(δ) = 27/(2 − δ²) непрерывны и уникальны на всей лестнице (точная
теорема), но **препятствие тика немонотонно по δ и НЕ селектирует
выживший кирпич δ_C = π/7** — выбор кирпича остаётся наблюдением
(септиниальный сектор b_Ch), не машинным выводом; фантомный зазор π/30
сканом кирпичей не закрывается (лучший +1.14%).

Оговорки: на цепочке перепись исчерпывающая (точная факторизация); вне
цепочки — дискретная численная evidенция (300 стартов; изолированные
компоненты, не притягивающие ни один старт, не исключены); конвенция
кирпича κ(δ) = 2 − δ²/2 — записанная аддитивная бэрри-форма v11;
препятствие тика — локальная линейная метрика остановки подъёма.
