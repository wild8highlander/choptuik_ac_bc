# einstein_direct — прямое решение задачи Чоптюка из классических уравнений Эйнштейна

**Подробная документация — в [README_EN.md](README_EN.md) (14 разделов, английский).**

Кратко о модуле:

- **Машинный вывод** (SymPy + mpmath 50 знаков): действие Гильберта →
  уравнения Эйнштейна в 1+1 двойных нулевых координатах; верификация на
  точном решении Робертса–Оширо, невязки ~10⁻⁴¹ (все 5 связей).
- **Солвер**: характеристический марш (РК2-Хойн), 2-й порядок; плоское
  пространство 10⁻¹⁴; 5/5 регрессионных тестов.
- **Фиксированная сетка**: бисекция A* = 0.0805333 (N=1600); честный
  негативный результат по γ (массовый пол M ≈ 4·du при нуклеации горизонта).
- **Зум-машина v2/v3.2**: цепочка перерегрирований до z ≈ 5.9 (4 зума);
  v3.2 — регулярное замыкание центра (спинорная E/O-декомпозиция, связка
  наклонов s₁−t₁ = −2a, кубическая масса, проекция парностей); массовый
  мусор подавлен (3.56 → 6.6·10⁻⁵); стена глубины задокументирована.
- **Спинор-анализ (π/15, π/30)**: Z₂-зеркальные парности центра (A/B:
  клэмп 1.00 → regular 0.35 по чётной добавке p+q); соотношения фреймворка
  R1–R4, включая компенсацию в произведении γ·Δ до 0.04%; предсказание
  ω = 120/7; честные пределы данных (нужно z ≥ 30 — см. README_EN §11).


## Статус сравнения с гипотезой b_Ch = γ (честно)

| Величина | Здесь | Литература |
|---|---|---|
| γ (фикс. сетка) | 0.11 ± 0.11 — **невалидно** | 0.374 ± 0.004 |
| γ (зум-цепочка) | не достигнуто (стена z≈5.9) | — |
| Δ (эхо) | не достигнуто (нет чистого поезда эхо) | 0.7376 |
| b_Ch = 1−cos(2π/7) | **0.376510** (гипотеза) | +0.67% к γ_lit |
| Δ = 7π/30 | **0.733038** (фреймворк) | −0.62% к Δ_lit |
| γ·Δ | **0.275996** vs 0.275876 | **0.044%** |

Расхождения R1 и R2 почти компенсируются в произведении γ·Δ — см.
README_EN.md §11. Ничего из измеренного пока не подтверждает и не
опровергает гипотезу: нужен центральный Тейлор-патч (v5).
