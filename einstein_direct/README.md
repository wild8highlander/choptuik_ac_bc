# einstein_direct — Прямое решение задачи Чоптюка из уравнений Эйнштейна

**Direct solution of the Choptuik problem from the classical Einstein equations,**
derived from the Hilbert action with the Hilbert stress–energy tensor for matter.

## Что здесь / What is here

Задача Чоптюка решается «напрямую», без спектральных построений:

1. **Действие Гильберта** $S=(2\kappa)^{-1}\int\sqrt{-g}\,R + S_m$,
   $S_m=-\frac12\int\sqrt{-g}\,(\nabla\Phi)^2$ — варьирование по $g^{\mu\nu}$
   даёт уравнения Эйнштейна с **ТЭИ Гильберта**
   $T_{\mu\nu}=\partial_\mu\Phi\partial_\nu\Phi-\frac12 g_{\mu\nu}(\nabla\Phi)^2$;
2. **Двунулевая редукция** ($ds^2=-\alpha^2du\,dv+r^2d\Omega^2$) → замкнутая
   система 1+1 для $(r,\Phi,\omega=\ln\alpha,m)$;
3. **Машинная верификация** вывода (SymPy) на точном решении
   Робертса–Оширо (исправленная форма Бурко, gr-qc/9608061) — невязки
   $\sim10^{-41}$;
4. **Солвер 2-го порядка** (характеристический марш Хойна, неявное ОДУ для
   $\Phi_v$, регулярность в центре $t=s$, $p=-q$; масса Мизнера–Шарпа
   эволюцируется без сокращений);
5. **Бисекция критической амплитуды** $A_*=0.0805333$ и измерение скейлинга
   $M_{\mathrm{BH}}\propto(A-A_*)^\gamma$.

## Результаты / Results

| Величина | Значение | Статус |
|---|---|---|
| Вывод системы из действия Гильберта | совпадает с SymPy-выводом | ✓ машинно |
| Робертс–Оширо: невязки системы | $\max 4\cdot10^{-41}$ | ✓ 50 знаков |
| Плоское пространство | $8.8\cdot10^{-15}$ | ✓ машинно |
| Сходимость солвера | $p=2.03\text{–}2.09$ | ✓ 2-й порядок |
| Критическая амплитуда $A_*$ | $0.0805333$ (сетка $1600^2$) | ✓ |
| $\gamma$ (фиксированная сетка) | $0.11\pm0.11$ | пол разрешения |
| $\gamma$ (Чоптюк 1993) | $0.374\pm0.004$ | литература |
| $b_{\mathrm{Ch}}=1-\cos(2\pi/7)$ | $0.376510$ | фреймворк |

**Честный вывод:** на фиксированной сетке масса горизонта упирается в пол
$M\ge4\,\mathrm{d}u$ (порог нуклеации горизонта + критическое замедление),
поэтому фиксированная сетка не может верифицировать $\gamma=0.374$ и тем более
разрешить зазор $b_{\mathrm{Ch}}$ vs $\gamma$ в $0.67\%$. Для этого нужен
перерегриддинг уровня Чоптюка (3–4 декады по $A-A_*$); прототип —
`zoom_solver.py`.

## Запуск / How to run

```bash
cd einstein_direct
python3 sympy_derivation.py    # символьный вывод + проверка Робертса (10⁻⁴¹)
python3 solver.py              # самопроверка плоского пространства (10⁻¹⁴)
python3 roberts_test.py        # сходимость 2-го порядка
python3 choptuik_scaling.py    # бисекция A* + скейлинг + фит (~4 мин)
python3 zoom_solver.py         # прототип перерегриддинга (экспериментально)
python3 figures.py             # рисунки RU/EN (300 dpi)
```

Результаты: `results/*.json`, отчёты: `report_ru.pdf`, `report_en.pdf`.

## Единицы / Units

$4\pi G=1$, $\kappa=8\pi G=2$ (нормировка Бурко). Время забега $1200^2$ —
≈1 с (NumPy, векторизация по $u$).
