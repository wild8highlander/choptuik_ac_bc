# einstein_direct — прямое решение задачи Чоптюка из классических уравнений Эйнштейна

**Подробная документация — в [README_EN.md](README_EN.md) (14 разделов, английский).**

Кратко о модуле:

- **Машинный вывод** (SymPy + mpmath 50 знаков): действие Гильберта →
  уравнения Эйнштейна в 1+1 двойных нулевых координатах; верификация на
  точном решении Робертса–Оширо, невязки ~10⁻⁴¹ (все 5 связей).
- **Солвер**: характеристический марш (РК2-Хойн), 2-й порядок; плоское
  пространство 10⁻¹⁴; 5/5 регрессионных тестов.
- **Фиксированная сетка**: бисекция A* = 0.0805333 (N=1600); честный
  негативный результат по γ (массовый пол M ≈ 4·du при нуклеации горизонта).
- **Зум-машина v2/v3.2**: цепочка перерегрирований до z ≈ 5.9 (4 зума);
  v3.2 — регулярное замыкание центра (спинорная E/O-декомпозиция, связка
  наклонов s₁−t₁ = −2a, кубическая масса, проекция парностей); массовый
  мусор подавлен (3.56 → 6.6·10⁻⁵); стена глубины задокументирована.
- **Спинор-анализ (π/15, π/30)**: Z₂-зеркальные парности центра (A/B:
  клэмп 1.00 → regular 0.35 по чётной добавке p+q); соотношения фреймворка
  R1–R4, включая компенсацию в произведении γ·Δ до 0.04%; предсказание
  ω = 120/7; честные пределы данных (нужно z ≥ 30 — см. README_EN §11).

## v5: центральный Тейлор-патч (сессия 5)

Фундаментальный уровень выполнен: иерархия центра выведена МАШИННО
(`sympy_center.py`) и верифицирована SymPy (ОДУ O1–O5: связки чётной E-моды
и нечётной спинорной O-моды; форма O3 содержит член +W2, пропущенный ручным
выводом, форма O5 — коэффициент 2 при (R3·R1'/R1²)·P0'). Численные невязки
конвейера на подкритическом забеге: O2 ≈ 1.1e-3, O1 ≈ 2.8e-2.

Патч `center_closure="taylor"`: t0/d0 эволюционируют по ОДУ как внутреннее
ГУ (Чоптюк-1993), зона пересобирается из ряда (E(0) = t0 — эволюционирующая
величина), чётная паразита (p+q) проектируется с учётом смещения центра x*,
все фиты — с санитарными guards. p,q,r,alpha2 не трогаются (дискретная C1).

Итог честно: мусор массы у центра 2.9e-6; глубина цепочки до z = 7.19
(рекорд; финальная конфигурация z ≈ 4.2–4.5 — хаос, нужна однопоточная
BLAS); процентная γ и Δ по-прежнему НЕ достигнуты — стена сместилась из
центра в зеркальную асимметрию сырого марша вне зоны + хрупкий захват
горизонта (дорожная карта v6 — в README_EN.md §15 и
`results/zoom_campaign_v5.json`). Спинорная лестница π/15, π/30:

## v8: гексагональный Пуанкаре-цикл трансформаций (динамика вместо усечённой башни)

O6-вердикт сессии 8: ветвь UV[ξ³] форсирует T0² = 9/4 (τ₃ = (3/2)²), ветвь
Mdef[ξ⁵] — T0² = 9/16 (τ₅ = (3/4)²), вместе — только тривиальное R3 = 0: у
усечённой башни нет точного CSS-решения, источники принципиально динамичны.
`sympy_hexcycle.py` формализует ответ: вместо статического усечения —
динамический цикл шести станций (пирамида → конус → усечённый конус →
параболический пивот → чаша → лог-замыкание → пирамида) по уравнениям
Пуанкаре в квазискоростях на C₆-циферблате формы. Две несовместные ветви
становятся шагами двух РАЗНЫХ книг цикла:

- **амплитудная книга**: CORE-пара (3/2)² = τ₃, кольцевые пары (4/3)² = 1/τ₅,
  полный цикл κ_cyc = ln(τ₃/τ₅²) = ln(64/9) = 1.9617 против якоря
  κ_obs = Δ_sp/γ = 1.9600 (+0.085%); дефицит замороженной башни
  λ₊(27/80) = 1.5091 (+0.451 в κ) заполнен циклом на 100.4%;
- **часы эха**: −ln τ₅ = ln(16/9) за сторону гексагона, Δ_cyc = 6 ln(16/9) =
  12 ln(4/3) = 24 ln(2/√3) = 3.4522 против Δ = 3.44 (Чоптюк, 1993; внутри
  коридора ±0.02);
- **«6-угольные лог-вычисления» — точная геометрия**: шаг кольца 4/3 = (2/√3)²
  — квадрат отношения радиусов описанной/вписанной окружностей гексагона;
  ветви O6 сами квадраты (√τ₃ = 3/2, √τ₅ = 3/4, отношение 2 — удвоение
  пирамиды);
- **γ_cyc = Δ_sp/κ_cyc = 0.373683** (γ_lit = 0.374, −0.085%; b_Ch −0.75%);
- **аттрактор — предельный цикл (DSS, а не CSS)**: форма на сечении
  возвращается в пирамиду точно (ошибка 0), масштаб падает в e^Δ ≈ 31.6 за
  цикл — структурное объяснение наблюдения Чоптюка.

Машина: 15/15 символьных тождеств; уравнения Пуанкаре = Эйлера–Лагранжа
(абелева группа циферблата), запирание V'(kπ/3) = 0 всех шести станций,
p_θ = const в свободной циркуляции; период свободной циркуляции = Δ_cyc
точно (<10⁻¹²), запертой (V₆ = 0.05) — +0.253% (честный O(V₆)-эффект); шаг
книги измерен численно до 10⁻⁹. Аксиомы (разбиение 2+4, глобальные часы) и
ограничения — сформулированы честно (README_EN §18). Отчёты:
`hexcycle_report_ru.pdf` / `hexcycle_report_en.pdf`; рисунки RU/EN 300 dpi
(`fig_hexcycle*.png`).

## P4-замыкание (O6+): цикл форм в уравнениях Эйнштейна и Гильберта (сессия 11)

Машина: `sympy_p4_einstein_hilbert.py` -> `results/p4_einstein_hilbert.json`.

- **Как цикл живёт в классических уравнениях**: остатки double-null ЕСТЬ
  `G = κT` с точными факторами: `G_uu − κT_uu = −(2/r)·C1-форма`,
  `G_vv − κT_vv = −(2/r)·C2-форма`, `G_uv = −(2/r)·(UV + r(TH − st))`;
  `T_uv ≡ 0` (нуль-нуль сектор тензора Гильберта пуст); тождество Гильберта
  `∇_μT^μ_ν = (□Φ)∇_νΦ` — динамика источников и есть закон сохранения.
  Шесть станций цикла — режимы ОДНОГО тензора.
- **Кольцо и часы выведены**: ядро O1-O5 даёт `W2h = (4/3)T0²R1h` (кольцо
  `4/3 = (2/√3)²`) и `P2h = T0/3` (часы) — машина выводит, не постулирует.
- **Аудит точки session 8**: вторые производные источников (W2'', R3'', P4'')
  и R5' молча обнулялись; в исправленной системе ветви 9/4 и 9/16 сливаются
  в общий корень **τ\* = 27/4** — замороженная CSS-точка O6-башни существует
  (уникальна); двухкнижная конструкция `κ_cyc = ln(64/9)` опиралась на артефакт.
  В τ\* = 27/4: `T0h = 3√3/2`, `P2h = √3/2 = sin(π/3)` — гексагональное
  отношение появляется само; спектр λ⁺(27/4) ≈ 8 — точка не аттрактор.
- **Пролонгация O7**: сохранение ядра вдоль потока убивает адиабатические
  динамические точки (V1/V2 нарушают, V3 замкнута только на замороженной);
  подлинная динамика источников требует вторых потоков — предельный цикл (DSS).
- **Чистое d-поле**: `c ↔ d` при зеркале, `(d−c) = ω_ξ = 2W2ξ` нечётно;
  экстрактор `[(d−c)(ξ) − (d−c)(−ξ)]/(4ξ)` гасит чётный мусор точно;
  v8-пары асимметричны (leak 0.92) — каналу W2/t0² нужны зеркальные пары (v9).

Файлы: `sympy_p4_einstein_hilbert.py`, `results/p4_einstein_hilbert.json`.
Запуск: `python3 sympy_p4_einstein_hilbert.py` (~15 с).

## v11: три поправки репозитория (b-C, a-C, a-B) в башнях (сессия 15)

Машина: `sympy_spinor_corrections.py` -> `results/spinor_corrections.json`.

**Вопрос автора.** Может, в уравнениях Эйнштейна есть «ошибка», требующая
выправления ради замыкания на π/30, — и настоящая причина в том, что мы
сознательно не встраивали три вычисленные поправки репозитория (b-C Бэрри,
a-C торможение, a-B) как естественные функции и формулы. Исправят ли они
башни?

**(0) Поправки как точные функции (кросс-чек по монографии OK).**
Фазы Γ(2,3,7): δ_A = π/2, δ_B = π/3, δ_C = π/7. Бэрри β(δ) = δ²/2,
торможение α(δ) = δ⁵/22 (k = b₂(K3) = 22): bC = π²/98 = 0.100710,
aC = 8.2763e-4 (≈1/1200), aB = (π/3)⁵/22 = 0.057243.

**(1) Аудит дверей: «ошибки» нет — есть СТРУКТУРА.**
С поканальными связями (κ_C1 в C1: (κ/2)rs², κ_C2 в C2: (κ/2)rt², κ_TH в TH:
(κ/2)st) символьная пересборка показывает: SC/UV/Mdef БЕЗ κ (утечек ноль —
ремонтировать нечего); карта каналов точная; **связка кольца** (новая
машинная теорема): C1-невязки в точке цепочки обнуляются ⟺ **κ_C1 = κ_C2**;
**связка ветвей**: UV_xi3 = −2T0h²(8κ₂²T0h² − 93κ₂ − 15κ_T) и
Mdef_xi5 = −2T0h²(4κ₂²T0h² − 39κ₂ − 15κ_T) имеют общий положительный корень
⟺ **κ_C2 = κ_T** (разность 15(κ₂−κ_T)/(8κ₂²)).

**Следствие: голономная поправка может править башню ТОЛЬКО как РАВНОМЕРНАЯ
перенормировка κ → κ_hol во всех трёх каналах.** Асимметричное встраивание
(a-B только в C1) убивает CSS-точку: C1-невязка 0.386 (машинная
демонстрация). Это предсказание башни о допустимой форме поправок.

**(2) Исправленное семейство ТОЧНО: `τ*(κ) = 27/(2κ)`.**
При равномерной перенормировке точка существует при любом κ > 0:
T0h² = 27/(2κ) (неисправленная точка — член κ = 2); **лестница станций
голономно-инвариантна** (R3h = 3/2, W2h = 9, R5h = 183/40, M5h = −105/4,
массовая связка M3*/R1* = 9/2, часы P2h/T0h = 1/3 — всё без κ); двигаются
само основание τ*, P2h = T0h/3, P4h ~ κ^{−1/2} и отношения к T0h²:
**кольцо W2h/T0h² = 2κ/3** (4/3 — член κ = 2; цель v9 становится
2κ_hol/3), R3h/T0h² = κ/9. Книга: ln τ* = ln(27/(2κ)).

(p, n) ∈ {0,1,2,4}×{1,2,3}; в частности cₙ,ₙ = 1 для ВСЕХ (n, p):
**выбор «коэффициент 1» dd-слотов (сеанс 17, заимствованный из прецедента
ddQ) теперь ВЫВЕДЕН, а не заимствован.**

  линейный остаток монодромии.**

### Вердикт сеанса

(a) паттерн (λ+a)(λ+b)(λ+c)F обобщается ТОЧНО (весовое правило); таблицы
третьего порядка существуют и верифицированы — и не добавляют ничего в
линейный спектр (пролонгационная инвариантность); (b) независимый закон dd
СУЩЕСТВУЕТ и ВЫНУЖДЕН: пролонгационное замыкание — единственное решение
выведенного из тождеств сохранения ограничений (ранг Uk = 9), альтернативы
вырождены машинными фактами, подгонки нет нигде; (c) δ_mono теперь
ИЗМЕРЕН, а не только выведен: 0 с честными границами (рост ~1e−13, фаза
~1e−7 за эхо — фазовая граница задаётся полом дефектности). **Остаток
«барионной асимметрии» башни — конечно-амплитудный феномен: весь линейный
мир (статика + де-адиабатизованные вторые потоки + третьий порядок)
аннигилирует точно. Следующая кампания: нелинейный марш DAE.**

Запуск: `python3 sympy_third_order.py`, `python3 sympy_dd_closure.py`
(экспорт .npy нужен для (c)), `python3 march_delta_mono.py`.
