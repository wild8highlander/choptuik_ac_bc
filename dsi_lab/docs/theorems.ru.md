# Слой теорем DSI-лаборатории

Метки статусов: **[доказано]** — точное доказательство; **[доказано +
верифицировано]** — доказательство плюс машинная численная проверка с
фиксированными сидами; **[опровергнуто]** — утверждение *неверно*, и
пакет хранит опровергающие данные. Lean 4: точный слой в
`lean4/DSILab.lean` (без sorry); теоремы A/B/C анкерованы аксиомами,
документированными верифицирующим экспериментом.

---

## T1 — острая теорема следа **[доказано + верифицировано]**

Для любых n и любой пары X₁, X₂ ∈ M_n(C):

```text
F(X₁,X₂) ≥ 5n/7,      e = F/n ≥ 5/7,
```

где F — кунцевский дефект. Случай равенства — скалярная пара
X₁ = X₂ = √(4/7)·I, которая *не* частичная изометрия (сингулярное число
√(4/7) ≠ 1). Численная проверка: L-BFGS-минимизация с рестартами при
n = 7..12 ложится на пол с зазором ≤ 5.92e-8
(`results/exp1_sh3.json`, `theorem_big_n.minimization`); точный
рациональный минимум семейства масштабированных перестановок
7t² − 8t + 3 при t = 4/7 верифицирован в Lean
(`scaled_permutation_minimum`).

## T2 — тождество дерева Кунца **[доказано + верифицировано]**

Для обрезки дерева Кунца глубины k (n = 2^(k+1) − 1 вершин, сдвиги S₁, S₂
с непересекающимися образами на depth ≥ 1):

```text
F(S₁, S₂) = n + 2   точно,     e = 1 + 2/n → 1.
```

Набросок доказательства: `I − S₁S₁* − S₂S₂*` имеет ранг 1 (выживает только
корень), а теорема T4 ниже превращает ранг 1 в «+2». Верифицировано до
|err| ≤ 5.7e-14 при k = 2..10 (`exp1_sh3.json`, `tree.truncation`;
`exp7_e1_threshold.json`, `theorem_B`). Lean: арифметический слой T4.

## T3 — формула взвешенного дерева **[доказано + верифицировано]**

Для взвешенного дерева Xᵢ = cᵢ·Sᵢ:

```text
F = (n−1)·[(c₁²−1)² + (c₂²−1)²] + n + 2,
```

минимум при c₁ = c₂ = 1: **никакое взвешивание не улучшает обрезку**, и
5/7 взвешенное дерево не достигает. Верифицировано до 1e-9 при k = 2..7
на нескольких весах (`exp1_sh3.json`, `tree.weighted`). При c² = 4/7,
k = 3 значение равно точно 549/49 — доказано в Lean
(`weighted_tree_549_49`).

## T4 — теорема A (порог) **[доказано + верифицировано]**

Для частичных изометрий X₁, X₂ ∈ M_n (ненулевые сингулярные числа равны 1):

```text
F(X₁,X₂) ≥ n,      т.е.  e ≥ 1.
```

*Доказательство (5 строк).* Для частичных изометрий P = X₁X₁*, Q = X₂X₂* —
проекции, p = rank P, q = rank Q, r = tr(PQ), и аудированное тождество
F = G(P,Q) = 3n − 2p − 2q + 3r. Размерность даёт
max(0, p+q−n) ≤ r ≤ min(p,q). Если p+q ≥ n: F − n = 3r − 2(p+q−n) ≥
3(p+q−n) − 2(p+q−n) = p+q−n ≥ 0; если p+q ≤ n: F − n = 2(n−p−q) + 3r ≥ 0. ∎

Равенство ⟺ P·Q = 0 и p + q = n (комплементарные проекции). Численная
проверка: тождество F = 3n − 2p − 2q + 3r выполняется до 5.9e-16 на
24 000 случайных пар, нарушений порога — **ноль**
(`exp7_e1_threshold.json`, `theorem_A`). Lean: `theorem_A_threshold`
(аксиомно-анкерована), следствие D из неё выведено.

## T5 — теорема B (точная арифметика покрытия) **[доказано + верифицировано]**

Если X₁ = P, X₂ = Q — проекции с P + Q ≤ I, то

```text
F = n + 2·rank(I − P − Q)   точно.
```

В частности, обрезанное дерево Кунца не накрывает только корень:
rank(I − P − Q) = 1 и F = n + 2. Верифицировано на случайных
непересекающихся проекциях (макс. |err| = 2.3e-13) и на дереве k = 2..10
(`exp7_e1_threshold.json`, `theorem_B`). Lean: арифметический слой.

## T6 — теорема C (унитарные пары) **[доказано + верифицировано]**

Если X₁, X₂ унитарны, то

```text
F = 2n  точно   (e = 2);
```

дефект целиком от перекрытия ‖X₁*X₂‖² = n. Перестановочные модели —
частный случай. Верифицировано: макс. |F − 2n| = 2.8e-14 на унитарных и
перестановочных парах (`exp7_e1_threshold.json`, `theorem_C`).

## T7 — следствие D (замыкание класса) **[доказано]**

inf e по носитель-изометрическим парам равен 1; значение 5/7 в классе
недостижимо, значит мост Ш.3(iii) (софичные амлификации, гонящие дефект
в ноль) невозможен для изометрических переносов: η ≡ 1 > 0. Это
усиливает цепочку Ш1–Ш4: Ш2 верна на всём классе. Lean:
`corollary_D_class_closure` (выведено из T4, без sorry).

## T8 — софический √ε-закон опровергнут **[опровергнуто]**

Гипотеза «естественные переносы софичных данных с ошибкой ε гонят
e → 0 как C·ε^(1/2)» **неверна** в проверенном классе: случайные
подстановки с долей неподвижных точек ε, переносимые как c·P с
оптимальным c, держат дефект плоским (скан Хэмминга в `exp1_sh3.json`,
`hamming`). Данные сохранены как честный негатив.

## T9 — переписная лемма (тождество валентностей) **[доказано]**

Для тилинга {7,3} квартики Клейна, построенного как пространства смежных
классов G = GL(3,2) ≅ PSL(2,7):

```text
V = 56,  E = 84,  F = 24,   7F = 3V = 2E = |G| = 168,   V − E + F = −4.
```

Перепись элементов (1, 21, 56, 42, 48 по порядкам) и силовские числа
n₂ = 21, n₃ = 28, n₇ = 8 верифицированы в явном перечислении
(`exp6_census_224.json`, `census`). Lean: `census_valence_identity`,
`census_euler` (без sorry).

## T10 — лемма единственности для 9/224 **[доказано + верифицировано]**

Среди дробей p/q с q ≤ 5000, p ≤ 32, чей знаменатель 7-гладкий в
переписном бюджете (v₂ ≤ 6, v₃ ≤ 1, v₇ ≤ 1), дробь 9/224 — **единственная**
в пределах 0.1 % (и подавно 0.01 %) от измеренного c_K3; среди подходящих
дробей цепной дроби c_K3 переписной фильтр проходят только 1/24 и 9/224
(`exp6_census_224.json`, `census_filter`). Lean: слой цепных дробей
(`cf_9_224_*`, `cK3_eq_cf`).

## T11 — теорема о вырождении родового семейства **[доказано]**

На башне Гурвица два структурных прочтения DSI-4,

```text
ветвь I  : c_I(g)  = 27/(4|G|) = 9/(4V)            ~ (g−1)⁻¹
ветвь II : c_II(g) = (N−1)/(F·N),  N = 14(g−1)      ~ (g−1)⁻¹·(1−1/N),
```

совпадают **только при g = 3** (квартика Клейна), а ветвь III фреймворка
c_III(g) = b_Ch(b₂(g)) ~ (g−1)⁻² отделяется уже при g = 7. Следствие:
одно измерение амплитуды DSI на любой старшей поверхности Гурвица
различает механизмы (`exp6_census_224.json`, `genus`).

## T12 — находка D1 (строка Гурвица) **[доказано, исправление]**

Строка репозитория (g = 14, n = 11) невозможна: 84·13 = 1092 не делится
на 11, элемента порядка 11 не существует. Правильная группа рода 14 —
PSL(2,13) сигнатуры (2,3,13); исправленная башня проходит все три
проверки (84(g−1) = |G|, n | |G|, 1/2 + 1/3 + 1/n < 1), и кривая
фреймворка даёт Δ_Ch(π/13) = 3.3672 (`exp3_hurwitz.json`).

## T13 — фальсифицируемый закон обертонов **[верифицировано, фальсифицируемо]**

Из закоммиченного QNM-каталога: |Δf_n|/f_n = const = 8.3857e-5 по
лестнице обертонов GW150914, обнаружимость обертонов 0.84σ на Cosmic
Explorer. Это *предсказание* фреймворка, устроенное так, что один
нулевой результат его убивает (`exp4_qnm.json`, `overtones`).

## T14 — находка E1 (центрирование QCD) **[верифицировано, исправление]**

След tr(Q_K3 ⊕ M_F) = 32 существует только после центрирования ⟨λ⟩; на
центрированной башне |⟨λ⟩| масштабируется как 1/√N с наклоном −0.99, и
κ_T-sweep даёт BF(GUE) до 1165 против Пуассона (`exp5_qcd.json`,
`nscaling`, `kappa_sweep`). Честная оговорка: V_T остаётся
конструктивной моделью T-нарушения, не выводом.

## Открытые проблемы пакета

1. **Ш.3(iii) без изометрий** — могут ли *не*изометрические переносы
   пробить пол, T4–T7 не затрагивают; замыкание класса говорит лишь о
   смерти изометрического маршрута.
2. **Вывод DSI-4** — совпадение +0.0025 % для 9/224 — наблюдение с
   леммой единственности, но не вывод из DSI-ренормализации.
3. **b₂ на старших поверхностях Гурвица** — паттерн 2b+2 — структурная
   гипотеза фреймворка (помечена как таковая в эксперименте 3).
